# 농산물 가격 예측
### 중간 발표 — ML 파트 · 2026-08-28

---

## 1. 우리가 하려는 일

회사는 **저장 트레이딩**으로 돈을 벌려고 합니다.

```
경매에서 싸게 산다  →  창고에 넣어둔다  →  값이 오르면 판다
```

이 계획은 딱 한 가지 질문에 답할 수 있어야 성립합니다.

> **"앞으로 3주 동안 값이 오를까, 내릴까?"**

**우리 파트는 이 질문 하나만** 맡습니다. 얼마나 살지, 창고비가 얼마인지,
얼마나 썩는지는 다른 파트가 정합니다. 우리는 **가격 곡선**을 넘깁니다.

### 왜 3주인가

오늘 산 배추는 몇 주 보관할 수 있습니다. 그래서 **앞으로 18영업일**을
예측합니다 — 내일, 모레, 계속해서 18일째까지.

---

## 2. 왜 어려운가

농산물 값은 휴대폰 값과 다릅니다. **많이, 그리고 빨리** 움직입니다.

```
배추 경락가, 우리 DB 에서 실제로 잰 값
  평균           777원/kg
  싼 날          300원/kg 근처
  비싼 날        2,000원/kg 넘음
```

태풍 하나로 시장 전체가 한 달 만에 바뀝니다. 실제로 있었던 일입니다 —
**2022년 9월 태풍 힌남노**: 배추가 **8월 1,237원/kg → 9월 2,072원/kg**,
68% 뛰었습니다.

---

## 3. 무엇을 만들었나

네 가지입니다.

| # | 만든 것 | 하는 일 |
|---|---|---|
| 1 | **데이터 파이프라인** | 5종류 데이터를 매일 모으고, 다듬고, 합침 |
| 2 | **모델 3개** | 경락가 · 중도매가 · 소매가 |
| 3 | **매일 도는 로봇** | 아침 09:00 에 사람 없이 혼자 돎 |
| 4 | **전달용 표** | 다른 파트가 DB 에서 바로 읽어감 |

### 데이터 규모 (2026-08-27 실측)

| 원천 | 행 수 | 기간 |
|---|---|---|
| 경락가 (가락시장) | **1,560,545** | 2017-01-02 ~ 2026-08-26 |
| 중도매가 + 소매가 | **1,044,591** | 2015-01-02 ~ 2026-08-26 |
| 기상 (관측소 95곳) | **401,753** | 2015 ~ 2026 |
| 반입량 (얼마나 들어왔나) | 18,280 | 2014-12 ~ 2026-08-27 |
| **학습표 (전부 합친 것)** | **198,829행 · 56컬럼** | 고유 날짜 2,857개 |

우리가 계속 되뇌는 경고가 하나 있습니다.

> **198,829행은 198,829개의 문제가 아닙니다.** 하루가 최대 54행으로 복제됩니다
> (3품목 × 18리드타임). **진짜 표본은 2,857일**입니다.

이걸 헷갈리면 데이터가 **70배 많아 보입니다.**

## 4. 가격은 하나가 아니라 셋

배추 한 포기는 우리 손에 오기까지 세 번 주인이 바뀌고, **그때마다 값이 다릅니다.**

```
농가 ──[경매]──▶ 중도매인 ──[판매]──▶ 가게 ──[소매]──▶ 소비자
        ▲                    ▲                  ▲
   우리가 사는 값          중간 값          우리가 파는 값
```

**셋 다 예측합니다.** 트레이딩은 양쪽 끝이 다 필요하기 때문입니다 —
경락가로 사고, 소매가로 팝니다.

## 5. 이걸 되게 만든 아이디어

### 틀린 방법 — 가격을 맞힌다

처음 모델은 "9월 10일 배추는 850원" 을 맞히려 했습니다.

**교묘하게 실패했습니다.** 모델이 **며칠 뒤를 예측하는지를 무시**했습니다.
1일 뒤 예측과 18일 뒤 예측이 거의 같은 답을 냈습니다.

실패를 숫자로 잴 수 있었습니다.

```
모델이 "며칠 뒤인가" 를 얼마나 중요하게 봤나    1.5%    ← 거의 안 봄
1일 뒤 예측 성적                              −95%    ← 형편없음
```

모델은 그냥 **평균 가격을 외워서 반복**하고 있었습니다.

### 맞는 방법 — 변화를 맞힌다

대신 **어제보다 얼마나 움직이는지**를 예측합니다.

```
학습    y = log( 맞힐 가격 ÷ 어제 가격 )
예측    가격 = 어제 가격 × e^(모델 출력)
```

**비유.** 내일 기온을 맨땅에서 맞히려 하지 마세요. **오늘 기온에서 출발해서
얼마나 움직일지**를 맞히세요. 훨씬 쉬운 질문이고, 오늘 기온은 공짜로 압니다.

**이 하나로 모델이 비로소 작동했습니다.**

## 6. 우리를 어떻게 채점하나 — 여기가 제일 중요합니다

"우리 모델 좋아요" 는 누구나 말할 수 있습니다. 그래서 **스스로를 속일 수 없게**
규칙을 만들었습니다.

### 규칙 1 — baseline 을 이겨야 한다

**baseline** 은 **계산 없이 그냥 낼 수 있는 기준값**입니다. 우리는 네 개를 씁니다.

```
① 어제 가격          ② 최근 7일 평균
③ 최근 14일 평균     ④ 작년 같은 날 가격
```

이걸 못 이기면 **모델은 쓸모가 없습니다.** 그냥 baseline 을 쓰고 전기를
아끼는 게 낫습니다.

시험 점수와 같습니다. "60점" 만으로는 잘한 건지 모릅니다.
**반 평균을 알아야** 판단됩니다. baseline 이 그 반 평균입니다.

### 규칙 2 — baseline 중에서도 **가장 센 것**과 비교한다

이건 크게 데였습니다.

> 반입량 모델이 **"baseline 보다 +40% 좋다"** 고 보고한 적이 있습니다.
> "어제 값" 하나에만 대본 결과였습니다. 계절을 심하게 타는 값이라 훨씬 똑똑한
> baseline 인 **"작년 같은 주"** 와 대보니 진짜 값은 **+15.3%** 였습니다.
> **약 8배 부풀린 것**입니다.

이 문서의 모든 숫자는 이제 **넷 중 가장 센 것**과 비교한 값입니다.

### 규칙 3 — 서로 다른 두 해에서 결과가 같아야 한다

입력 하나를 채택하려면 **서로 다른 시험 연도 두 곳**에서 도움이 돼야 하고,
그 도움이 **실행할 때마다 생기는 흔들림보다 커야** 합니다.

이 규칙이 이미 그럴듯해 보이던 아이디어들을 잘랐습니다.

| 아이디어 | 시험 2023 | 시험 2022 | 판정 |
|---|---|---|---|
| 학사일정 (급식 수요) | +0.0036 도움 | −0.0017 해로움 | **기각** |
| 경제지표 (M2, PPI) | 해로움 | 해로움 | **기각** |

학사일정은 한 해만 봤다면 **"+3.7% → +5.6%, 큰 성과"** 로 발표됐을 값입니다.

### 규칙 4 — 조건 없는 숫자는 적지 않는다

```
나쁨   "경락가 정확도 0.1702"
좋음   "경락가 WMAPE 0.1702 (배추·양파·무 · 학습 2017~2022 ·
        검증 2023 · 앵커변환 · 시드5 · feature 31)"
```

조건 없는 숫자는 **아무도 검증할 수 없습니다.** 우리 자신도요.

## 7. 결과

### 7.1 실전 — 9개월치 예측을 실제 값으로 채점

**실험실 숫자가 아닙니다.** 미리 예측해 두고, 진짜 값이 나올 때까지 기다렸다가
비교한 것입니다.

**2025-11-25 ~ 2026-08-26 · 채점된 예측 76,614건 · 게이트 걸린 행 제외**
**비교 대상: 우리 모델 vs "어제 가격"**

| 가격 종류 | 품목 | 우리 오차 | baseline (어제 가격) | 우리가 나은 정도 | 구간 적중률 |
|---|---|---|---|---|---|
| **경락가** | 배추 | **21.11%** | 30.90% | **+31.7%** | 80.0% |
| **경락가** | 양파 | **13.67%** | 17.31% | **+21.0%** | 69.7% |
| **경락가** | 무 | 21.68% | 21.53% | **−0.7%** | 80.4% |
| **소매가** | 배추 | **7.75%** | 9.06% | **+14.5%** | 90.4% |
| **소매가** | 무 | **7.91%** | 9.00% | **+12.1%** | 86.3% |
| **소매가** | 양파 | **7.46%** | 8.57% | **+13.0%** | 80.1% |

> **조건.** 여기 비교 대상은 **"어제 가격" 하나**이고, 네 개 중 가장 센 것이
> 아닙니다. §7.2 의 실험실 숫자는 엄격한 규칙을 적용한 값입니다.

**"구간 적중률" 읽는 법.** 우리는 숫자 하나만 주지 않습니다. **범위**를 줍니다.
일기예보가 "비 올 확률 70~80%" 라고 하는 것과 같습니다. 진짜 값이 우리 범위
안에 **10번 중 8번** 들어오는 걸 목표로 합니다. 실측이 69~92% 이니
**범위가 정직합니다** — 자신 있어 보이려고 좁게 조이지 않았습니다.

**소매가가 가장 튼튼합니다. 세 품목 전부 양수, 전부 +12% 이상.**

**"시드 흔들림" 이 왜 중요한가.** 모델은 돌릴 때마다 답이 조금씩 다릅니다.
그 흔들림이 ±0.0004~0.0014 인데 개선폭은 그보다 **수십 배 큽니다.**
운이 좋아서 나온 숫자가 아니라는 뜻입니다.

## 8. 이번 프로젝트에서 찾은 가장 큰 것

### 우리 정답지가 틀려 있었습니다

1년 넘게 **사실상 무작위 잡음**을 정답으로 놓고 모델을 다듬고 있었습니다.
어제(2026-08-27) 알았습니다.

### 어떻게 찾았나

아무도 물어본 적 없던 **작은 이상함**에서 시작했습니다.

```
1. 매입 파트가 가격 범위를 요청       → 우리 범위를 점검
2. 배추 범위가 유독 넓음 (0.65)       → 이유를 파봄
3. 하루 중 최고가가 19,900원/kg       → 평균 939원의 21배
4. 원천 API 를 직접 호출
5. 원천은 거래 건별이고, 건마다 포장 규격이 있음
6. 규격별로 갈라봄  →  하루치에 15개 상품이 섞여 있었음
```

그 `19,900` 은 **2015년부터 DB 에 있었습니다.** 어떤 검사도 이걸 본 적이
없었습니다.

### 무엇이 문제였나

원천은 **거래 한 건당 한 줄**을 줍니다. 그런데 우리 수집기가 **그날 거래를
전부 평균**내고 있었습니다 — 포장이 다르면 **다른 상품**인데도요.

**배추 · 특등급 · 가락시장 · 하루치 (2026-08-03):**

| 포장 | 원/kg | 물량 |
|---|---|---|
| **그물망 10kg** | **711** | **322,940kg (79%)** |
| 상자 8kg | 1,721 | 35,640kg |
| 상자 4kg | 5,841 | 3,744kg |
| 상자 1kg | **11,224** | 2,278kg |
| …11종 더 | | |
| **가중평균 = 우리 옛 타겟** | **939** | 410,960kg |

소포장이 대량 그물망보다 **kg당 15배 비쌉니다.** 게다가 아예 다른 채소가
"배추" 로 들어와 있었습니다 — **쌈배추, 수입배추, 생채용.**

**비유.** 우유 1L 한 통(1,000원)과 200mL 한 통(800원)을 평균 내서
**"우유 L당 가격"** 이라고 부르는 것과 같습니다. 작은 통은 **L당 4,000원**
입니다. 평균은 숫자이긴 하지만, **실제로 살 수 있는 물건의 값이 아닙니다.**

### 왜 예측이 불가능해졌나

가장 확실한 측정은 **어제 가격이 오늘 가격을 얼마나 알려주나**입니다.

```
혼합 타겟     0.085     ← 어제가 거의 아무것도 안 알려줌. 사실상 무작위
규격 고정     0.901     ← 어제가 많이 알려줌
```

**0.085 는 예측이 불가능하다는 뜻입니다.** 어떤 feature 를 넣어도 나아질 수
없었습니다. **찾을 것이 애초에 없었기 때문**입니다. 1년 동안 **동전 던지기를
맞히려고** 모델을 다듬은 셈입니다.

다른 증상들도 **몇 년째 보이고 있었습니다.**

| 검사 | 혼합 | 규격 고정 |
|---|---|---|
| 어제 → 오늘 연결 | 0.085 | **0.901** |
| 계열이 퍼진 정도 | 0.919 | 0.354 |
| 하루 안 최고 ÷ 최저 | **132.7배** | 9.7배 |
| 특등급이 상등급보다 **싼** 날 | **815일 중 737일** | 해소 |

**특등급이 상등급보다 싼 날이 90%** 라는 건 진짜 시장에서 불가능합니다.
크게 울리는 경보였는데 아무도 확인하지 않았습니다.

### 고치는 것도 두 번 틀렸습니다

**1차 — "무게가 같으면 같은 상품"** 포장 형태는 열어두고 10kg만 걸었습니다. 틀렸습니다.

```
배추 10kg 안에서:  그물망 824 · 파렛트 943 · 상자 1,115 · 비닐봉지 3,071원/kg
```

**비닐봉지 10kg 이 그물망의 3.7배**입니다. 무게가 같아도 다른 상품입니다.

**2차 — 포장 목록을 모든 품목에 공통 적용** `그물망 / 상자 / 파렛트` 로 묶었더니
배추가 **0.928 → 0.513** 으로 떨어졌습니다. 무 때문에 넣은 `상자` 가 배추에서는
**소포장 계열**이었기 때문입니다.

**포장 형태는 품목마다 따로 정해야 합니다.** 확정:

| 품목 | 포장 | 중량 | 어제→오늘 연결 | 물량 비중 |
|---|---|---|---|---|
| 배추 | 그물망, 파렛트 | 10kg | 0.901 | 94% |
| 무 | 상자, 파렛트 | 18kg(~2017) → 20kg | 0.928 | 76% |
| 양파 | 그물망, 파렛트 | 15kg | 0.979 | 71% |

무는 **2018년에 업계 포장 표준이 바뀌어서** 연도로 나눴습니다.
안 나누면 0.373 으로 떨어집니다.

### 그리고 전부 다시 만들었습니다

```
재수집     1,560,545행  ·  API 약 12,000회
사전 백업  781,405행 · 153MB
이관 실행  98초
```

**대표 숫자에 대한 경고 하나.** 오차 점수가 **0.1801 → 0.2127** 로 올라
**나빠 보입니다. 아닙니다. 타겟이 바뀐 것**입니다. 옛 타겟은 소포장 고가가
섞여 평균이 939원으로 부풀어 있었고, 진짜 대량 시장가는 777원이라 **같은
퍼센트 오차라도 나누는 수가 작습니다.** baseline도 같이 어려워졌고
(0.2557 → 0.3078), **그런데도 우리 모델이 이겼습니다.**

> **타겟이 바뀌면 오차 점수를 서로 비교하면 안 됩니다.**
> 대신 **baseline 과의 격차**를 비교하세요.

### #1·#2 에 대해 — 이유를 찾았습니다

배추 경락가는 2022 에서 아주 잘하고(+19.5%) 2023 에서는 겨우 넘습니다(+3.9%).
반대로 양파는 파는 쪽이 2022 에서만 음수입니다.
조사해 보니 **2022 는 태풍이 든 유일한 시험 연도**였습니다.

**이게 모든 걸 다시 보게 만듭니다.** 모델은 **공급 충격 때 값어치를 내고**
조용한 해에는 별로 보태지 않습니다. 그리고 앞서 기각한 아이디어 두 개도
**틀린 이유로 기각했을 수 있습니다** — 그것들은 *충격이 든 해*에서 실패했는데,
그건 "쓸모없다" 가 아니라 **"충격기에는 쓸모없다"** 일 수 있습니다.

> **두 시험 연도가 엇갈리면, 먼저 그해에 무슨 일이 있었는지 찾아보세요.**

### #4 에 대해 — 자리를 못 찾은 숫자

매입 파트가 실측이라며 **"배추 1,850 vs 1,650"** 을 들었습니다. 우리 배추
가격은 **610원/kg** 이라 자릿수가 아예 다릅니다. 찾아봤더니 그 숫자가
**매입 파트의 mock 시험 파일에 그대로 박혀** 있었고, 주석에 **"명세 문서의
예시와 동일한 값"** 이라고 적혀 있었습니다.

**진짜 데이터가 아니라 예시 데이터와 비교하고 있었던 것**입니다.
양쪽 다 뭘 바꾸기 전에 이것부터 확인해야 합니다.
