# 경매 가격 예측 발표 대본

두 실험 결과와 하이퍼파라미터 조정 내용을 반영한 2장 발표용 대본입니다.
발표 시간은 약 1~2분입니다.

## 1장. 경매 가격 예측 방법

### 슬라이드 내용

- 대상: 배추·무·양파
- 예측 기간: 최대 18영업일
- 모델: LightGBM 4.7.0
- 예측 방식: 가격 자체가 아닌 기준 가격 대비 변화량 예측
- 앵커: 어제 가격 60% + 최근 7일 평균 40%
- 5개 모델(seed 42~46)의 예측 평균

### 주요 하이퍼파라미터

| 설정 | 값 |
|---|---:|
| 학습률 | 0.03 |
| 트리 잎 개수 | 31 |
| 잎당 최소 데이터 | 60개 |
| 특성 사용 비율 | 80% |
| 데이터 사용 비율 | 80% |
| L2 규제 | 1.0 |
| 손실 함수 | L1 회귀 |
| 트리 수 | 53개 |

### 발표 대본

저희는 배추·무·양파의 경매 가격을 최대 18영업일 앞까지 예측합니다.

가격 자체를 바로 맞히는 대신, 어제 가격과 최근 7일 평균을 기준으로 앞으로 가격이 얼마나 변할지를 예측합니다. 이번에는 어제 가격 60%와 최근 7일 평균 40%를 섞어 기준 가격으로 사용했습니다.

모델은 LightGBM 4.7.0을 사용했고, 같은 모델을 무작위 조건을 바꾸어 5번 학습한 뒤 결과를 평균 냈습니다. 이렇게 하면 특정 한 번의 우연한 결과에 덜 영향을 받습니다.

주요 설정으로는 학습률 0.03, 트리 잎 개수 31개, 잎당 최소 60개 데이터, 특성과 데이터 사용 비율 각각 80%, L2 규제 1.0, L1 손실 함수를 사용했습니다. 최종 모델은 53개의 트리를 사용했습니다.

이 값들은 고정된 것이 아닙니다. 정확도와 안정성을 높이기 위해 학습률, 트리 크기, 데이터 사용 비율 등을 계속 바꾸어 가며 실험하고 있습니다. 다만 설정을 바꿀 때마다 여러 검증 기간에서 다시 확인하고, 한 기간에만 잘 맞는 설정은 사용하지 않습니다.

## 2장. 실험 결과

### 슬라이드 내용

- 학습 기간: 2017~2023년
- 검증 기간: 2024~2026년
- 학습 기준일: 1,718일
- 검증 기준일: 645일
- 전체 WMAPE: 0.1507
- 기준 방법 대비 전체 8.7% 개선

| 품목 | 기준 대비 개선율 | 평균 오차율 |
|---|---:|---:|
| 무 | +3.4% | 18.4% |
| 배추 | +13.1% | 18.9% |
| 양파 | +7.6% | 9.5% |

### 앵커 실험 결과

- 기존 방식: 어제 가격만 사용
- 새 방식: 어제 가격 60% + 최근 7일 평균 40%
- 2023년 검증: 기준 대비 −3.2% → +3.4%
- 2022년 검증: 기준 대비 +7.1% → +7.4%

### 발표 대본

먼저 앵커를 바꾸는 실험을 했습니다.

기존에는 어제 가격만 사용했는데, 2023년에는 최근 7일 평균을 사용하는 단순한 방법보다 3.2% 낮은 성능이었습니다. 하지만 어제 가격 60%와 최근 7일 평균 40%를 섞자 기준보다 3.4% 좋은 결과가 나왔습니다.

2022년에는 태풍으로 가격이 크게 변했지만, 새 방식도 기준보다 7.4% 좋은 결과를 보였습니다. 따라서 평상시와 급격한 변화가 있는 시기 모두에서 비교적 안정적인 0.6 비율을 선택했습니다.

이 설정을 실제 경매 가격 모델에 적용한 결과, 전체 WMAPE는 0.1507이었고 기준 방법보다 8.7% 개선되었습니다. 품목별로는 무 3.4%, 배추 13.1%, 양파 7.6% 좋아졌습니다.

평균 오차율은 무 18.4%, 배추 18.9%, 양파 9.5%였습니다. 경매 가격은 변동이 크기 때문에 오차가 아직 큰 편이지만, 18영업일 뒤 예측에서도 기준 방법보다 12.2% 좋은 결과를 보였습니다.

결론적으로, 이번 모델은 새로운 알고리즘 하나보다 적절한 기준 가격을 찾고, 하이퍼파라미터를 반복해서 검증한 결과 성능이 좋아졌습니다. 앞으로도 설정을 계속 조정하되, 여러 기간에서 안정적으로 작동하는지를 함께 확인할 예정입니다.
