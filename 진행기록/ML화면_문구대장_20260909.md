# 화면 문구 한국어로 옮기기 — 농산물 가격 예측 화면

## 무엇을 해 주셔야 하나

아래 표의 **「지금 영어」를 한국어로 옮겨** 주세요. 184개입니다.

### ★ 「예전 한국어」 칸을 그대로 쓰지 마세요

이 화면은 원래 한국어였습니다. 그런데 **「무슨 말인지 알아들을 수가 없다」는
지적을 받았습니다.** 그래서 영어로 한 번 옮겼고, 지금 그것을 다시 한국어로
쓰는 중입니다.

「예전 한국어」 칸은 **원래 무슨 뜻이었는지** 확인하시라고 넣은 것입니다.
**베끼지 마세요.** 그 글이 어려워서 이 일을 하는 것입니다.

```
지금 영어      No verdict
예전 한국어    판정 불가          <- 이게 어렵다는 지적을 받았습니다
새로 쓸 것     알 수 없음         <- 이런 쪽으로
```

### 돌려주실 형식

**`ID → 새 한국어`** 한 줄씩만 주세요. 표 전체를 다시 보내지 마세요.

```
PG-011 → 기준일 (이 예측을 만든 날)
VT-013 → 알 수 없음
RT-021 → 지금 판정하기
```

문장 안의 `{...}` 는 프로그램이 숫자나 날짜를 끼워 넣는 자리입니다.
**그대로 두시고 위치만 옮기셔도 됩니다.**

```
지금 영어   Range {lo}–{hi} · width {w}
가능        폭 {w} · 구간 {lo}–{hi}
안 됨       구간 445–712 · 폭 0.48        <- 실제 숫자로 바꾸면 안 됩니다
```

**마지막에 한 가지만 알려 주세요** — 5절 낱말표에서 정한 한국어 낱말을
목록으로 적어 주세요. 그 낱말이 화면 곳곳에 나오기 때문입니다.

## 1. 이 화면이 무엇인가

농산물 **가격을 예측**해서 **싸게 사고 비싸게 파는** 것을 돕는 사내 화면입니다.
한국 회사에서 씁니다.

```
산지 → [경매] → 중도매인 → [판매] → 식당·소매상 → [소매] → 소비자
        ↑                                          ↑
   경락가 Auction                            소매가 Retail
   (우리가 사는 값)                          (우리가 파는 값)
```

경매는 **밤에** 섭니다. 그래서 「오늘 밤 경매에서 얼마에 살까」를 아침에
예측합니다.

### 읽는 사람

**사내 매입·재무 담당자**입니다. 농사 전문가도, 머신러닝 전문가도 아닙니다.
숫자를 보고 **오늘 얼마에 사야 하나**를 정하는 사람들입니다.

### 화면은 탭 넷

| 탭 | 무엇을 보나 |
|---|---|
| Forecast | 오늘부터 18영업일 가격 예측. 점을 누르면 왜 그렇게 봤는지 |
| Batch | 매일 아침 9시에 도는 일이 잘 돌았나 |
| AI reports | 데이터가 이상한지 · 오늘 뉴스 · 지난 기록 |
| Retraining | 예측 모델을 다시 배울까 · 바꿀까 |

## 2. 말투 규칙 — **이게 제일 중요합니다**

> **초등학생도 알아들을 수 있게 씁니다.** 전문 용어를 쓰면 바로 옆에 풀이를
> 붙입니다. 못 붙이겠으면 그 단어를 안 씁니다.

지켜야 할 것 다섯.

**① 짧은 문장.** 한 문장에 한 가지만.

**② 결론 먼저, 이유 나중.**

**③ 숫자를 그대로.** 「크게 개선」 말고 「10번 중 6번 → 8번」.

**④ 나쁜 소식을 순화하지 않습니다.** 쉽게 쓰는 것과 흐리는 것은 다릅니다.
이 화면에는 「우리 예측이 얼마나 틀리나」를 대놓고 적은 자리가 여럿 있습니다.
그건 일부러 그렇게 쓴 것입니다. 부드럽게 바꾸지 마세요.

**⑤ 없는 값을 0 처럼 말하지 않습니다.** 「아직 모른다」와 「0이다」는 다릅니다.
이 구분이 흐려지면 사람이 잘못된 확신을 갖습니다.

**왜 이런 규칙이 있나** — 설명이 어려우면 읽는 사람이 맞는지 틀린지 판단하지
못하고 그냥 넘어갑니다. 그러면 화면을 보여주는 의미가 사라집니다.

### 길이

버튼과 표 머리는 **짧아야 합니다.** 길어지면 표가 가로로 밀려서 못 읽습니다.

```
버튼         2~5 글자      예) 「판정하기」 「바꾸기」
표 머리       2~4 글자      예) 「품목」 「대상일」
아주 짧게     2~3 글자      예) 「리드」 「예」
카드 제목     4~8 글자
설명 문장     길어도 됩니다
```

각 줄의 「어디에」 칸에 버튼인지 표 머리인지 적어 두었습니다.

## 3. 절대 바꾸면 안 되는 것 ★

아래 값들은 **화면 글자처럼 보이지만 사실은 프로그램끼리 주고받는 열쇠**입니다.
바꾸면 **오류 하나 없이 조용히 아무것도 안 나옵니다.**

```
배추 · 무 · 양파          품목 이름. 데이터베이스가 이 이름으로 담고 있습니다
auc · whsl · rtl          가격 종류 코드
ops_auc · ops_whsl        모델 이름. 다른 부서가 이 이름으로 찾습니다
{...} 로 감싼 것           숫자·날짜가 끼워지는 자리
```

**이것들은 아래 표에 아예 넣지 않았습니다.** 표에 있는 것만 고쳐 주시면 됩니다.

## 5. 낱말표 — 여기부터 정하고 시작하세요

**한 낱말이 화면 곳곳에 나옵니다.** 여기서 먼저 정하고, 정한 대로 아래 표
전체를 맞춰 주세요.

「예전 한국어」 칸의 낱말도 **바꾸셔도 됩니다.** 다만 하나만 봐 주세요 —

> **업계에서 실제로 쓰는 말은 그대로 두는 편이 낫습니다.**
> 「경락가」·「중도매가」는 매입 담당자가 매일 쓰는 말입니다. 쉽게 바꾸려고
> 「경매 가격」으로 고치면 오히려 「그게 경락가인가?」 하고 되묻게 됩니다.
> **어려운 말과 익숙한 말은 다릅니다.**
>
> 반대로 「앵커」·「리드타임」·「폴드」는 우리끼리 쓰던 말이라 바꾸는 게 낫습니다.

### ★ 지금 어긋나 있는 것 — 고쳐 주세요

**「어제 가격」을 두 이름으로 부르고 있습니다.** 표에서는 `Anchor`(앵커),
그래프에서는 `Start`(출발점). **같은 것입니다. 하나로 정해 주세요.**

해당 줄: `VT-003` · `FC-004` · `FC-008` · `FC-009`

이건 「어제 가격을 그대로 오늘 예측으로 쓴 것」입니다. 예측이 이것보다
나쁘면 모델을 쓸 이유가 없어서, 화면 여러 곳에서 견주는 기준이 됩니다.
