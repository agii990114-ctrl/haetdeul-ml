# 학사일정 feature — 구축과 기각

2026-08-24 · 백로그 M-08 "개학·방학 캘린더 (급식 수요)"

---

## 결론 먼저

**기각했습니다.** 3폴드 × 3타겟 9개 조합에서 O 판정은 하나뿐이고 세 타겟 모두
부호가 갈렸습니다. `crop_price_train` 컬럼과 `ref_school_day` 테이블은 남기되
모델 입력에서는 기본 제외입니다.

가설은 "중도매가 사용자가 식당·급식 구매담당이니 방학이 수요에 직접 걸린다"
였습니다. **정작 중도매가가 가장 나빴습니다.**

---

## 1. 시작 지점 — 손에 있던 것

`DB/데이터/학사일정/` 에 NEIS 학사일정 CSV 71개(2020-09~2026-07)와,
집계본 `ref_school_day_seoul.csv` 가 있었습니다. 집계 스크립트는 없었습니다.

원본을 열어보니 세 가지 문제가 있었습니다.

**① 파일명과 내용이 어긋납니다.** "2024년10월" 이 실제로는 10/09~11/08 을
담습니다. 31일 창으로 받은 흔적입니다. 이어붙여도 **8곳 45일**이 빕니다.

```
2024-09-30 → 10-09 (8일)    2024-12-31 → 2025-01-08 (7일)
2025-02-07 → 02-20 (12일)   2025-11-30 → 12-08 (7일)   … 총 8곳
```

**② 일요일이 "개교"로 잡힙니다.** NEIS 가 일요일에 휴업일 행을 만들지 않아
실측 일요일 중앙값이 0.995 입니다. 조사 축(`target_dt`)에 일요일이 없어
실무 영향은 없지만 프로파일을 오염시킵니다.

**③ 이게 진짜 문제였습니다 — 학습 구간 커버리지 36.6%**

| 구간 | 실측 |
|---|---|
| 학습 2017~2022 | 803/2,191일 · **36.6%** |
| 검증 2023 | 97.5% |
| 테스트 2024~25 | 88.5% |

이대로 넣으면 **결측 여부가 "2020-09 이전인가" 라는 시점 식별자**가 됩니다.
경제 변수를 제거한 것(5.2), `crop_area_yoy_rt` 를 DROP 에 넣은 것과 같은 구조입니다.

## 2. 추가 수집이 가능한가 — 불가능

`open.neis.go.kr` 학사일정 API 를 직접 찔러 확인했습니다.

```
DATA 개방일 2019-04-01
서울 경기초등학교(7031110) 조회:
  2026-03 ✓ 23건   2026-08 ✓ 24건   2025-03 ✓
  2024-03 ✗   2023-03 ✗   2022-03 ✗  …  2017-03 ✗
→ 보유 = 최근 2개 학년도
```

**개방일이 2019-04 이므로 2017-01~2019-03(27개월)은 원천적으로 존재하지 않습니다.**
최선을 다해도 결측을 없앨 수 없습니다.

## 3. 그래서 연중 프로파일

실측 5년으로 **(월,일) 중앙값 프로파일**을 만들어 2015~2028 전 구간에 같은
규칙을 적용했습니다. 전 구간이 같은 성격이 되고, 배치에서 미래 리드타임도
채울 수 있습니다.

프로파일 산출에서 토·일과 공휴일을 제외했습니다. 일요일은 위 ② 때문이고,
공휴일 휴교는 `ref_calendar` 가 이미 담당합니다. **결국 학사일정이 새로 주는
정보는 여름·겨울방학뿐입니다.**

실측에서 뽑은 방학 경계는 놀랄 만큼 안정적이었습니다.

```
여름방학  2021 7/21~8/18 · 2022 7/22~8/17 · 2023 7/21~8/15
          2024 7/24~8/15 · 2025 7/23~8/15 · 2026 7/23~
겨울방학  12월 말 ~ 2월 말 (3/1 직후 종료, 매년 일관)
```

**검증 — leave-one-year-out**

해당 연도를 빼고 만든 프로파일로 그 해를 맞춥니다.

| 연도 | n | MAE | 급식일 이진 일치 |
|---|---|---|---|
| 2021 | 249 | 0.0424 | 95.2% |
| 2022 | 247 | 0.0324 | 96.4% |
| 2023 | 247 | 0.0286 | 96.4% |
| 2024 | 241 | 0.0272 | 96.7% |
| 2025 | 224 | 0.0252 | 97.8% |
| **가중평균** | **1,428** | **0.0315** | **96.7%** |

규칙으로 바꾸면서 잃은 신호가 3% 남짓입니다.

월별 평균: 1월 0.23 · 2월 0.21 · 3~6월 0.96~1.00 · 7월 0.71 · 8월 0.49 ·
9~11월 0.99 · 12월 0.94.

## 4. 판정 — 기각

조건: 학습 2017~ · 배추·양파·무 · 시드 10개 · LT 게이트 미적용.
손실 = WMAPE(제거) − WMAPE(전체). 양수면 기여했다는 뜻입니다.

| 타겟 | A(검증2023) | B(검증2022) | C(검증2021) | 합산 | 편차×2 |
|---|---|---|---|---|---|
| 경락가 | **+0.0036 O** | −0.0017 △ | +0.0027 △ | +0.0046 | 0.0028 |
| 중도매가 | +0.0011 △ | −0.0014 △ | −0.0009 △ | −0.0012 | 0.0023 |
| 소매가 | −0.0002 △ | +0.0005 △ | −0.0005 △ | −0.0002 | 0.0012 |

채택 조건(5.7)은 "폴드 두 개 이상에서 부호가 같고 합산이 편차×2 초과" 입니다.
**세 타겟 모두 부호가 갈려 미충족**입니다.

**폴드 A 만 봤다면 채택했을 것입니다.** 경락가 +3.7% → +5.6%, +1.9%p 였습니다.
한 해 검증으로 결정하지 않는다는 규칙이 두 번째로 실제 결정을 바꿨습니다
(첫 번째는 auction 그룹).

## 5. 남은 관찰 — 폴드 B 가 두 번째로 예외

`volume` 3폴드 재판정에서도 음수는 폴드 B 하나뿐이고 A·C 는 세 타겟 모두
양수였습니다. **서로 무관한 feature 두 개가 같은 폴드에서만 반대 방향**인 것은
우연으로 보기 어렵습니다.

폴드 B 는 학습에 코로나기(2020~2021)가 들어가고 검증이 회복기 2022 입니다.
판정 규칙을 바꿀 근거는 아니고 관찰로만 남깁니다. **세 번째 사례가 나오면
조사할 것.**

## 7. 다시 볼 만한 변형 (지금은 하지 않음)

- **개학·방학 전환 신호** — `school_open_ratio` 의 14일 변화량. 유통이 개학에
  대비해 미리 물량을 잡는다면 수준값보다 전환이 맞을 수 있습니다.
- **초등학교 한정** — 급식 규모가 가장 크고 방학이 가장 깁니다.
- **소매가 한정** — 소매는 가구 수요라 개학이 장바구니에 걸릴 여지가 있으나,
  이번 판정에서 소매가 손실이 세 폴드 모두 편차 이하였습니다.

세 가지 모두 근거가 약합니다. 다른 P3 후보(휴장 일수, 등급 스프레드,
타 도매시장 경락가)가 먼저입니다.
