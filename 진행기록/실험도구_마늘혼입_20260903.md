# ★ 실험 도구가 운영과 다른 자료로 학습하고 있었다 — 마늘 24% 혼입

## 한 줄로

**넉 달 가까이, 실험은 마늘을 넣고 학습하고 운영은 빼고 학습했습니다.
오늘 채택한 feature 하나가 무효가 됐고, [M-12] 의 결론이
"채택 하나" 에서 "변경 없음" 으로 바뀌었습니다.**

**배포된 모델은 정상입니다.** 실험 도구만 달랐습니다.

## 1. 무엇이 어긋나 있었나

```
운영 학습  train.py            DEFAULT_ITEMS = ["배추","양파","무"]   마늘 제외
실험 도구  exp_quantile.build()  품목 필터가 없음                     마늘 포함
```

마늘은 **학습 행의 24%** 입니다 (45,010 / 198,883).

`build()` 를 쓰는 스크립트가 **14개**입니다.

```
ablation_ops.py   auto_research.py   band_oos.py      chk_holiday.py
exp_blank_holiday.py   exp_holiday_nan.py   exp_kimchi_def.py
exp_loo_single.py   exp_mlp.py   exp_models.py   exp_nsi.py
exp_quantile.py   exp_top1_share.py   make_llm_prompt.py
```

> **5.12절("비교는 운영이 쓰는 자리에서 한다")을 실험 도구 자체가
> 어기고 있었습니다.** 그 규칙은 XGBoost 를 300그루에서 재고
> "XGBoost 가 낫다" 고 잘못 보고한 뒤에 만든 것입니다.
> **같은 잘못을 한 층 아래에서 하고 있었습니다.**

## 2. 왜 하필 마늘인가 — 성격이 아주 다릅니다

CLAUDE.md 5.4절에 마늘을 뺀 이유가 적혀 있습니다.

```
중도매가가 94% 의 날에 전일과 동일   <- 예측 문제로서 성격이 다름
경락가 결측 11%  (타 품목 1%)
가격 수준 6,244원/kg  (배추 963 · 무 771 · 양파 1,098)
서울 소매 데이터 없음
```

**8절의 경고도 마늘 이야기입니다** — "마늘이 분모의 66%를 차지해
통합값을 0.2114 → 0.0781 로 끌어내린 사례가 있다".
**그 함정을 알고 있었는데 학습 쪽은 못 봤습니다.**

## 4. 무효가 된 것

### [M-12] `auc_prc_spread_lag1` 채택 — 취소

```
마늘 포함(잘못된 조건)   배추 +0.0028 / +0.0028   합산 +0.0056   ★ 채택
마늘 제외(운영 조건)     배추 +0.0002 / +0.0008   합산 +0.0010   판정 불가
```

**효과가 사라졌습니다.** 스프레드가 배추에 해롭게 보였던 것은
**마늘을 같이 학습시켜 생긴 착시**였습니다.

### ★ 재현으로는 못 걸렀습니다

이 값은 **한 번도 쓴 적 없는 시드(82~101)로 다시 재서 재현까지 됐던**
값입니다.

```
시드 62~81    +0.0028 / +0.0028   통과
시드 82~101   +0.0033 / +0.0021   통과   <- 재현됨
```

> **재현은 "같은 실수를 두 번 해도 같은 답이 나온다" 는 뜻일 뿐입니다.**
> **조건 자체가 틀리면 재현성으로는 안 걸립니다.**
> 오늘 세 번 쓴 "새 시드로 확인" 절차의 한계입니다.

### [M-12] 최종 결론 — **feature 변경 없음**

올바른 조건으로 다시 재니 **36칸 전부 판정 불가**입니다 (채택 0).

```
auc_vol_lag1          12칸 전부 판정 불가
auc_prc_spread_lag1   12칸 전부 판정 불가
kimchi_season_yn      12칸 전부 판정 불가
```

## 5. 살아남은 것

### 명절 feature (무 행에서 비우기) — 유지. 오히려 더 분명해졌습니다

| 타겟 | 품목 | 마늘 포함 | 마늘 제외 | 판정 |
|---|---|---|---|---|
| 경락가 | 무 | +0.0175 | **+0.0165** | ★ 비우는 게 낫다 |
| 경락가 | **통합** | +0.0019 (판정 불가) | **+0.0039** | **★ 비우는 게 낫다** |
| 중도매가 | **배추** | −0.0033 (판정 불가) | **−0.0083** | **★ 그대로 두는 게 낫다** |
| 소매가 | 배추 | −0.0033 | −0.0033 | ★ 그대로 두는 게 낫다 (동일) |

**"경락가에만 적용" 권고는 그대로이고 근거가 세졌습니다.**
경락가는 통합까지 개선되고, 중도매가는 배추 손해가 **판정 불가에서
확정으로** 바뀌어 "적용 안 함" 이 더 분명해졌습니다.

### 소매가 결과 전부 — 그대로 유효

마늘이 애초에 없어 **차이가 정확히 0.0000** 입니다.

## 6. 다시 봐야 하는 과거 결론

**배포된 번들은 전부 `train.py` 로 만들어 3품목입니다** (`meta.json` 의
`items` 로 확인). **지금 나가는 예측이 틀렸다는 뜻이 아닙니다.**
다시 봐야 하는 것은 **판정의 근거**입니다.

| 결론 | 스크립트 | 위험 |
|---|---|---|
| **분위수 q 값 (5.11절)** | `exp_quantile.py` | **높음 — 오늘 운영 반영함** |
| ablation 3차 "변경 없음" (5.7절) | `ablation_ops.py` | 중간 (null 결과) |
| 밴드 out-of-sample 적중률 | `band_oos.py` | 중간 |
| 부스팅 비교 기각 (5.12절) | `exp_models.py` | 낮음 (null) |
| MLP · 뉴스심리지수 · 트렌드 기각 | `exp_mlp/nsi/trend.py` | 낮음 (null) |
| autoresearch 587회 0채택 | `auto_research.py` | 낮음 (null) |
| LLM 시험의 LightGBM 비교값 | `make_llm_prompt.py` | 중간 |

**null 결과는 채택으로 뒤집힐 가능성이 낮지만 0은 아닙니다.**
q 값부터 다시 재고, 9/17 통계에 넣습니다.

## 7. 막는 방법 — 도구가 스스로 말하게

`build()` 가 **학습에 무엇을 썼는지 매번 찍습니다.**

```
[학습 품목] 배추, 양파, 무  (198,883행 중 153,873행 · 뺀 행 45,010)
```

> **오늘 매입 파트와 주고받은 그 이야기입니다** — "검사가 돌았나" 가
> 아니라 **"검사가 실제로 무엇을 봤나"**. 그림자 실행이 자기 자신과
> 비교하면서 계속 "성공" 으로 찍히던 것과 같은 계열입니다.

## 8. 이번에 배운 것

**① 재현성은 조건 오류를 못 잡는다.**
새 시드로 두 번 재현된 값이 무효였습니다. **재현은 "우연이 아니다" 만
말해주고 "맞는 것을 쟀다" 는 말해주지 않습니다.**

**② 도구는 결과보다 먼저 의심한다.**
오늘 세 실험이 전부 같은 도구를 썼습니다. **결과 세 개를 검증하는 것보다
도구 하나를 검증하는 것이 쌉니다.** 새 실험을 시작할 때
**"이게 운영과 같은 자료를 쓰나" 를 먼저 찍어 봅니다.**

**③ 우연히 걸렸다.**
[M-06] 주산지 비중 실험에서 **"비중이 빈 행 24%"** 경고가 떠서 알았습니다.
그 경고는 원래 프로파일이 제대로 붙었는지 보려고 넣은 것이었습니다.
**안 넣었으면 오늘도 몰랐습니다.**
