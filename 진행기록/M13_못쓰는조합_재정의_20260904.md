# [M-13] 못 쓰는 조합 — **목록이 틀렸습니다. 문제는 "중도매가" 하나입니다**

작성 2026-09-04 · 햇들농산 ML 파트 (지환) · 백로그 M-13

**백로그가 적은 "9개 중 3개" 는 낡았습니다. 2026 실전 164개 기준일로
다시 재니 경락·소매는 여섯 칸 다 좋고, 안 되는 것은 중도매가 셋입니다.

## 0. 먼저 — 재려면 자료가 있어야 했습니다

오차 이력이 **1월과 8월 말뿐이고 2~8월이 통째로 비어** 있었습니다.
기준일이 27개였습니다.

**그 27개로 재고 하마터면 틀린 결론을 낼 뻔했습니다.**

```
27개(1월에 몰림)로 재니   9칸 중 6칸이 "앵커에 진다"
구간을 갈라 보니          6칸이 부호가 뒤집힘
8~9월 표본               21~28행 (일주일치) · -253.8% 같은 값이 나옴
```

그래서 **2026 기준일 137개를 백필**했습니다 (2024~2025 는 봉인이라 제외).
지금 164개 기준일 · 21,734행이 채점돼 있습니다.

## 1. 새 목록 (2026 · LT≥3 · 수축 앵커 대비 · 분기별 부호까지 확인)

| 조합 | 연간 개선율 | 분기 부호 | 판정 |
|---|---|---|---|
| 소매 배추 | **+16.9%** | 일치 양수 | 좋음 |
| 경락 양파 | **+16.4%** | 일치 양수 | 좋음 |
| 경락 배추 | **+13.5%** | 일치 양수 | 좋음 |
| 소매 양파 | **+12.0%** | 일치 양수 | 좋음 |
| 소매 무 | **+10.1%** | 일치 양수 | 좋음 |
| 경락 무 | +1.6% | **갈림** | 판정 불가 |
| **중도매 무** | +0.4% | **갈림** | 앵커 수준 |
| **중도매 배추** | **−2.3%** | **갈림** | 앵커 수준 |
| **중도매 양파** | −0.3% | — | **평가 불가** (아래) |

**경락·소매 여섯 칸 중 다섯이 분기 부호까지 일치하는 양수입니다.**
**중도매 셋만 앵커 수준이거나 아래입니다.**

### ★ 중도매 양파는 "나쁘다" 가 아니라 "잴 수 없다" 입니다

```
2026 중도매 양파 2,652행 중 2,604행(98%)이 품질 게이트로 앵커 대체
```

**차단된 조합은 예측이 안 나가므로 평가도 안 됩니다.** 지금 숫자
(모델 8.41% = 앵커 8.41%)는 **앵커를 앵커와 견준 값**입니다.
다시 판정하려면 게이트를 끄고 그림자로 돌려 봐야 합니다.

> 스스로 성립하는 차단입니다 — 막았으니 못 재고, 못 재니 계속 막힙니다.

## 2. ★ 왜 중도매만 어려운가 — 쟀습니다

```
전일과 값이 똑같은 날의 비율 (2026)
   경락가     0.6 ~  1.3%
   소매가    18   ~ 26%
   중도매가  58   ~ 68%      <- 여기
```

**중도매가는 열흘 중 엿새가 어제와 값이 같습니다.**
그러면 *"어제값"* 앵커가 거의 완벽하고 모델이 낄 자리가 없습니다.

**하루 변화폭도 다릅니다.**

```
              하루 변화
   경락 배추    13.97%
   소매 배추     1.98%
   중도매 배추    1.61%
```

> **5.4 절에서 마늘을 뺀 이유가 이것이었습니다** —
> *"중도매가가 94%의 날에 전일과 동일. 예측 문제로서 성격이 다름."*
> **정도만 다를 뿐 배추·무·양파에도 그대로 적용됩니다** (58~68%).

### 실제로 앵커가 얼마나 센가

```
2026 Q1 중도매 배추   앵커 오차 3.30%   모델 6.69%
```

**앵커가 3.3% 면 이길 방법이 거의 없습니다.**

## 3. 그래서 M-13 의 과제를 다시 씁니다

**예전**: *"9개 조합 중 3개가 baseline 이하. 품목별 모델 분리 · 품목별 feature ·
양파 전용 앵커를 검토한다."*

**지금**: **품목 문제가 아니라 계열 문제입니다.** 중도매가 세 품목이 다 같은
모양이고, 경락·소매는 같은 품목인데 다 좋습니다. **품목별로 나눠도
"엿새는 안 움직인다" 는 성질은 그대로입니다.**

### 후보 (측정 전 · 순서는 기대치)

```
① 중도매가를 "얼마" 가 아니라 "바뀌나" 로 푼다
     바뀌는 날 32~42% 에만 값이 있다. 분류 문제로 바꾸면 다르게 보일 수 있다
     ⚠ 시험해 봤더니 배추는 맞고(바뀜 +5.8% · 그대로 -7.0%) 무는 반대다
       (바뀜 -4.0% · 그대로 +3.2%). **한 번에 안 풀립니다**

② 중도매 양파의 게이트를 그림자로 열어 본다
     지금은 평가 자체가 안 된다. 막은 근거가 낡았을 수 있다 (규격 고정 이전)

③ 중도매가에 경락가 신호를 더 준다
     경락(0.6% 동일)이 먼저 움직이고 중도매(58~68% 동일)가 따라간다면
     경락 -> 중도매 전이가 신호다. 지금 auc_prc_lag1 은 들어가 있지만
     "경락이 며칠째 오르는가" 같은 형태는 없다

④ 품목별 모델 분리
     ★ 기대치를 낮춥니다. 위 진단이 맞으면 이건 문제를 안 건드립니다
```

**④가 백로그의 첫 후보였는데 마지막으로 내립니다.**

## 4. 곁가지로 나온 것 둘

### ① 드리프트 감지 규칙이 틀렸었습니다 (같은 날 고침)

처음에 *"기준선(과거 중앙값)보다 10%p 아래면 나쁜 주"* 로 짰습니다.
**기준선이 높은 조합에서는 이기고 있는 주까지 '나쁜 주'** 가 됐습니다.

```
whsl 배추 기준선 +58.8% -> 문턱 +48.8%
   실제 세 주: +3.8% · -263.9% · +29.0%
   -> 두 주는 앵커를 이겼는데 "3주 연속 밀림" 이 울었다
```

그리고 개선율은 **비율**이라 앵커가 정확한 주에 폭발합니다
(앵커 4.0% · 모델 14.6% → −263.9%).

**오차의 차이(%p)로 바꿨습니다** — *"모델이 앵커보다 1%p 넘게 나쁘다"*.
부풀지도 폭발하지도 않고 뜻이 바로 읽힙니다. 고친 뒤 같은 조합이
**"최근 1주"** 로 정확히 나옵니다.

### ② 백필 자료는 매입 파트에 안 보냈습니다

`prediction_log`(우리 표)에만 넣었습니다. 저쪽은 1월분만 요청했고,
**더 밀지는 물어보고 하겠습니다.**
