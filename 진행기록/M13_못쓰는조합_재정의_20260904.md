## 2. ★ 왜 중도매만 어려운가 — 쟀습니다

```
전일과 값이 똑같은 날의 비율 (2026)
   경락가     0.6 ~  1.3%
   소매가    18   ~ 26%
   중도매가  58   ~ 68%      <- 여기
```

**중도매가는 열흘 중 엿새가 어제와 값이 같습니다.**
그러면 *"어제값"* 앵커가 거의 완벽하고 모델이 낄 자리가 없습니다.

**하루 변화폭도 다릅니다.**

```
              하루 변화
   경락 배추    13.97%
   소매 배추     1.98%
   중도매 배추    1.61%
```

> **5.4 절에서 마늘을 뺀 이유가 이것이었습니다** —
> *"중도매가가 94%의 날에 전일과 동일. 예측 문제로서 성격이 다름."*
> **정도만 다를 뿐 배추·무·양파에도 그대로 적용됩니다** (58~68%).

### 실제로 앵커가 얼마나 센가

```
2026 Q1 중도매 배추   앵커 오차 3.30%   모델 6.69%
```

**앵커가 3.3% 면 이길 방법이 거의 없습니다.**

## 3. 그래서 M-13 의 과제를 다시 씁니다

**예전**: *"9개 조합 중 3개가 baseline 이하. 품목별 모델 분리 · 품목별 feature ·
양파 전용 앵커를 검토한다."*

**지금**: **품목 문제가 아니라 계열 문제입니다.** 중도매가 세 품목이 다 같은
모양이고, 경락·소매는 같은 품목인데 다 좋습니다. **품목별로 나눠도
"엿새는 안 움직인다" 는 성질은 그대로입니다.**

### 후보 (측정 전 · 순서는 기대치)

```
① 중도매가를 "얼마" 가 아니라 "바뀌나" 로 푼다
     바뀌는 날 32~42% 에만 값이 있다. 분류 문제로 바꾸면 다르게 보일 수 있다
     ⚠ 시험해 봤더니 배추는 맞고(바뀜 +5.8% · 그대로 -7.0%) 무는 반대다
       (바뀜 -4.0% · 그대로 +3.2%). **한 번에 안 풀립니다**

② 중도매 양파의 게이트를 그림자로 열어 본다
     지금은 평가 자체가 안 된다. 막은 근거가 낡았을 수 있다 (규격 고정 이전)

③ 중도매가에 경락가 신호를 더 준다
     경락(0.6% 동일)이 먼저 움직이고 중도매(58~68% 동일)가 따라간다면
     경락 -> 중도매 전이가 신호다. 지금 auc_prc_lag1 은 들어가 있지만
     "경락이 며칠째 오르는가" 같은 형태는 없다

④ 품목별 모델 분리
     ★ 기대치를 낮춥니다. 위 진단이 맞으면 이건 문제를 안 건드립니다
```

**④가 백로그의 첫 후보였는데 마지막으로 내립니다.**

## 3-2. 후보를 둘 시험했습니다 — **둘 다 채택 없음**

### 후보 ③ 경락 → 중도매 전이 — **기각**

먼저 상관부터 쟀습니다 (2017~ · 기준일까지의 경락 3일 움직임 →
3~18일 뒤 중도매 변화).

```
양파   0.237 / 0.173 / 0.155      뚜렷
배추   0.109 / 0.119 / 0.088      약하지만 일관
무    -0.036 / -0.015 / -0.002    없음
```

**무에는 전이가 없습니다.** 그래도 3폴드로 돌렸습니다 — *없다*는 것도
기록해야 다음 사람이 또 안 뒤집습니다.

넣은 것은 **비율**입니다. `auc_prc_lag1·lag3·avg7` 은 이미 **수준**으로
들어 있지만 **트리는 나눗셈을 못 해서** 두 수준을 줘도 비율을 못 만듭니다.

```
auc_mom3 = auc_prc_lag1 / auc_prc_lag3
auc_mom7 = auc_prc_lag1 / auc_prc_avg7
```

**12칸 전부 갈리거나 편차x2 미달입니다.**

> **★ 그리고 시드 5개에서 보이던 것이 20개에서 사라졌습니다.**
>
> ```
> 양파 both   시드 5개   +0.53 / +1.67 / +0.36   "3폴드 일치 양수"
>             시드 20개  -0.07 / -0.38 / +0.90   ★ 갈림
> ```
>
> M-07 때와 같은 모양입니다. **부호 일치만 보고 편차×2 를 안 봤으면
> 채택할 뻔했습니다.**

### 후보 ①' 모델 출력 줄이기 — **기각. 그런데 다른 답이 나왔습니다**

처음 후보 ①은 *"바뀌는 날을 골라내자"* 였는데 **오차를 갈라 보니
반대**였습니다.

```
중도매가 오차 비중 (2026)
   무    바뀜 41.6%   그대로 58.4%
   배추  바뀜 34.3%   그대로 65.7%
```

**오차의 절반 넘게가 "값이 안 바뀐 날" 에서 나옵니다** — 앵커는 정확한데
**모델이 괜히 움직여서** 생긴 오차입니다. 그래서 방향을 뒤집었습니다.

```
pred = anchor * exp(λ · 모델출력)      λ 를 줄이면 덜 움직인다
```

**재학습이 필요 없습니다.** 결과가 좋으면 바로 반영할 수 있었습니다.

| 조합 | 폴드 A(6년) | 폴드 B(5년) | 폴드 C(4년) | 판정 |
|---|---|---|---|---|
| 중도매 배추 | λ=0.9 | λ=1.0 | λ=1.0 | 사실상 지금 그대로 |
| 중도매 무 | λ=1.0 | λ=0.8 | λ=0.0 | **갈림 — 못 고름** |
| 중도매 양파 | λ=0.4 (+3.3%) | λ=0.2 (+9.0%) | λ=0.2 (+17.1%) | 이득이 큼 |

**양파만 이득이 납니다. 그런데 그 이득이 학습 기간이 길수록 줄어듭니다.**

```
학습 4년 -> 최적 λ=0.2 (이득 +17.1%)
학습 5년 -> 최적 λ=0.2 (+9.0%)
학습 6년 -> 최적 λ=0.4 (+3.3%)
운영 7년 -> ?
```

**2026 실전에서는 λ=1(모델 그대로)이 앵커를 +12.7% 이깁니다.**
그러니 **운영에 λ 를 넣을 근거가 없습니다.** 폴드가 말하는 것은
*"학습이 짧으면 모델을 덜 믿어라"* 이고, **운영은 학습이 깁니다.**

### ★★ 그리고 이것이 중도매 양파 차단이 왜 낡았는지 설명합니다

**차단은 폴드(학습 4~6년)로 판정했습니다. 운영은 7년입니다.**

> **8절 그대로입니다** — *"절대 질문(이 조합을 쓸까)은 폴드로 안 됩니다.
> 폴드마다 학습 기간이 달라 상쇄가 안 됩니다."*
> 양파는 **학습 기간을 가장 많이 타는 품목**입니다 (소매 양파가
> 3년 −43.0% → 5년 +13.5%).

**차단 근거와 실전 결과가 어긋난 이유가 이것입니다.**
지금 그림자로 2주 더 보는 중이고, 그 결과가 같은 방향이면 풉니다.

### 후보 ④ 품목별 모델 분리 — **양파만 통과. 그런데 타겟마다 답이 다릅니다**

**기존 `exp_per_item.py` 는 못 씁니다** — 조기 종료(3000그루)·2폴드입니다.
운영은 고정 트리이고, 5.12 절에서 **트리 개수가 모델 종류보다 10배 크게
작용**한다고 쟀습니다 (5.7 ①: 조건이 바뀌면 판정은 만료).

**운영 조건 · 3폴드로 다시 쟀습니다.**

| 타겟 | 품목 | A(6년) | B(5년) | C(4년) | 판정 |
|---|---|---|---|---|---|
| 경락 | **양파** | +7.19 | +5.48 | +19.20 | **★ 나누는 게 낫다** |
| 경락 | 배추 | −4.28 | −3.82 | −2.46 | ★ 합치는 게 낫다 |
| 경락 | 무 | −0.74 | −2.55 | −11.90 | ★ 합치는 게 낫다 |

| 중도매 | 배추·무 | | | | ★ 갈림 |
| 소매 | 셋 다 | | | | ★ 갈림 |

**두 타겟에서 독립적으로 같은 결론입니다 — 양파만 따로 배워야 합니다.**

### 왜 양파만인가 — 계열 성질이 그대로 설명합니다

```
              배추·무          양파      양파가
경락 하루변화   11.09 / 11.93%   4.32%    2.7배 덜 움직인다
중도매 하루변화   4.98 /  5.34%   1.83%    2.8배
소매 하루변화    2.27 /  2.70%   1.69%    1.4배   <- 셋이 비슷
```

한 모델이 셋을 맞히려면 **절충**합니다. 경락·중도매에서는 양파가 워낙
조용해서 그 절충이 양파에 해롭습니다. **소매에서는 셋이 비슷해 절충
비용이 없고, 실제로 판정 불가로 나왔습니다.**

### ★ 그런데 배포 모양이 다릅니다 — 남는 둘을 따로 쟀습니다

```
쟀던 것    셋 묶음  ↔  양파 혼자
배포하면   배추·무 둘 묶음  +  양파 혼자
```

`exp_split_onion.py` 로 **배추·무 둘 묶음**을 쟀습니다 (음수 = 빼면 손해).

| 경락 | 무 | −4.01 | −0.85 | +0.16 | 갈림 — **손해가 증명 안 됨** |

## 4. 곁가지로 나온 것 둘

### ① 드리프트 감지 규칙이 틀렸었습니다 (같은 날 고침)

처음에 *"기준선(과거 중앙값)보다 10%p 아래면 나쁜 주"* 로 짰습니다.
**기준선이 높은 조합에서는 이기고 있는 주까지 '나쁜 주'** 가 됐습니다.

```
whsl 배추 기준선 +58.8% -> 문턱 +48.8%
   실제 세 주: +3.8% · -263.9% · +29.0%
   -> 두 주는 앵커를 이겼는데 "3주 연속 밀림" 이 울었다
```

그리고 개선율은 **비율**이라 앵커가 정확한 주에 폭발합니다
(앵커 4.0% · 모델 14.6% → −263.9%).

**오차의 차이(%p)로 바꿨습니다** — *"모델이 앵커보다 1%p 넘게 나쁘다"*.
부풀지도 폭발하지도 않고 뜻이 바로 읽힙니다. 고친 뒤 같은 조합이
**"최근 1주"** 로 정확히 나옵니다.

### ② 백필 자료는 매입 파트에 안 보냈습니다

`prediction_log`(우리 표)에만 넣었습니다. 저쪽은 1월분만 요청했고,
**더 밀지는 물어보고 하겠습니다.**
