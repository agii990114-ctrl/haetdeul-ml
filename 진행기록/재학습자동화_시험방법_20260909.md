# 재학습 자동화 — 직접 시험해 보는 법 (2026-09-09)

무엇을 만들었는지는 `agent/retrain_auto.py` 머리말에 있습니다.
이 문서는 **직접 눌러 보시는 순서**입니다.

---

## 준비 — 서버 넷

```bash
# 우리 저장소에서
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8102
cd frontend && npx next dev -p 3100

# mainproject 에서
cd backend  && .venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

화면은 `http://localhost:3000/console/forecast` 입니다.

> 요청으로 보고 막습니다. 화면이 하얗게 나옵니다.

## 시험 ① 바꿀 것이 없을 때 (30초 · 안전)

**아무것도 안 만지고** 「모델 재학습」 탭에 들어갑니다.
**탭은 늘 있습니다.** 갈리는 것은 탭 안입니다.

```
        현재는 모델을 업데이트할 필요가 없습니다.

  지금 쓰는 모델이 새로 학습한 모델보다 낫거나, 다시 배울 만큼
  성적이 밀리지 않았습니다.

  마지막 확인 2026-09-09 15:34:50 · 매일 아침 배치가 끝난 뒤 자동으로 봅니다
```

**탭에 빨간 뱃지가 없어야 맞습니다.** 뱃지는 바꿀 것이 있을 때만 붙습니다.

> 「마지막 확인」 시각이 중요합니다. **「아직 안 돌았다」 와 「돌았는데
> 없다」 는 다릅니다** — 앞은 고장일 수 있고 뒤는 정상입니다.

## 시험 ③ 진짜로 돌려 보기 — 만들고 · 견주고 · 지우기 (2분)

**문턱을 낮춰서** 강제로 후보를 만들게 합니다.

```bash
python agent/retrain_auto.py --kinds auc --streak 1 --gap-pp 0
```

`--streak 1` 은 「1주만 밀려도 후보로 본다」는 뜻입니다 (평소는 3주 연속).
**시험용 옵션이고 평소에는 안 줍니다.**

나오는 모습 (실측) —

```
[경락가] 도는 중 …
   후보가 못해서 지웠습니다  (63초)
   후보가 현행보다 못해 지웠습니다: ops_auc_cand_20260909

기다리는 결정 0개
```

### 이때 안전한 이유

**운영 모델을 한 글자도 안 건드립니다.** 새 번들을 옆에 만들어 견주기만
하고, 못하면 그 번들을 지웁니다. 바꾸는 것은 **사람이 화면에서 누를
때만** 일어납니다.

### 확인해 보실 것

```bash
# 후보 폴더가 지워졌나 — ops_auc_cand_2026<오늘> 이 없어야 맞습니다
ls ML/20260824/ml_train_kit_2/ | grep cand

# 현행과 백업은 그대로 있나
ls ML/20260824/ml_train_kit_2/ | grep "^ops_auc"
```

> `ops_auc_cand_20260907` · `ops_auc_cand_20260908` 은 **이 기능을 만들기
> 전에 손으로 돌려 남은 것**입니다. 지금 코드는 저런 걸 안 남깁니다.
> 지우셔도 됩니다.

## 시험 ④ 후보가 «나은» 경우는 어떻게 보나

**오늘 자료로는 후보가 이기지 않습니다.** 지금 모델이 더 낫기 때문이고,
그건 좋은 소식입니다. 그래서 「뱃지가 뜨는 진짜 경우」는 **시험 ②의 가짜
결정**으로 보시는 게 지금은 유일한 길입니다.

진짜로 이기는 날이 오면 이렇게 나옵니다.

```
[경락가] 도는 중 …
   ★ 후보가 낫습니다 — 사람이 «모델 업데이트» 를 눌러야 합니다  (63초)

기다리는 결정 1개
```

## 시험 ⑤ 「모델 업데이트」 버튼 — ★ 진짜로 바뀝니다

**이건 운영 모델을 실제로 교체합니다.** 눌러 보시려면 다음을 아셔야
합니다.

```
지금 것은 통째로 백업됩니다     ops_auc_교체전_<날짜>
모델 이름은 안 바뀝니다         매입 파트가 이름으로 찾습니다
되돌리는 창구가 있습니다        POST /retrain/rollback?kind=auc
```

**되돌리기**

```bash
curl -X POST "http://127.0.0.1:8102/retrain/rollback?kind=auc"
```

시험만 해 보실 거면 **누르지 않으시는 것을 권합니다.** 지금은 후보가
현행보다 못하다고 판정돼서, 눌러도 될 상황이 아닙니다.

## 시험 ⑥ 배치에 붙은 자리

`run_batch.py` 의 `push` 뒤에 들어갔습니다. 계획만 보려면 —

```bash
python run_batch.py --dry-run
```

**전달표를 보낸 뒤**에 돕니다. 학습이 종류당 1분쯤 걸려서, 앞에 두면
매입 파트가 그만큼 늦게 받습니다.

## 아직 안 해 본 것 — 알고 계셔야 합니다

```
후보가 이겨서 뱃지가 뜨는 전 구간   ★ 진짜 자료로는 아직 안 타 봤습니다
「모델 업데이트」 를 눌러 바뀌는 것   안 눌러 봤습니다
```

앞은 **재학습이 필요하다는 판정이 처음 나오는 날** 확인됩니다.
뒤는 그때 같이 확인하는 게 맞습니다 — 지금 누르면 더 나쁜 모델로
바꾸는 것이 됩니다.
