# Ablation 반영 후 최종 성능

> 실행일 2026-08-22 · 학습 2017~2022 / 검증 2023~2025 · 배추·양파·무

---

## 반영 내용

`train.py` 가 타겟별로 feature 를 자동 제외한다.

```python
ECON_COLS    = ["m2_growth_rt", "epu_idx", "ppi_idx"]
WEATHER_COLS = ["prod_area_stn_nm", "prod_area_temp_avg_lag1",
                "prod_area_rain_sum7", "prod_area_rain_sum30",
                "prod_area_gdd_sum30", "prod_area_clim_temp_avg10",
                "prod_area_clim_yr_cnt"]

TARGET_DROP = {
    "auc":  ECON_COLS,                    # → 31 feature
    "whsl": ECON_COLS,                    # → 31 feature
    "rtl":  ECON_COLS + WEATHER_COLS,     # → 24 feature
}
```

비교가 필요하면 `--keep-all` 로 되돌릴 수 있다.

## 품목별 최종

### 경락가 (매입 판단) — feature 31

baseline 0.1864 · 모델 0.1703 · **+8.6%**

| 품목 | baseline | 모델 | 개선율 | 방향정확도 |
|---|---|---|---|---|
| **배추** | 0.2618 | 0.2199 | **+16.0%** | **64.2%** |
| 무 | 0.2188 | 0.2105 | +3.8% | 60.0% |
| **양파** | 0.1008 | 0.1020 | **−1.2%** | 57.5% |

배추가 +11.0% → +16.0% 로 5%p 개선됐다. 방향정확도도 59.7% → 64.2%.

**양파는 −1.2% 로 baseline 보다 나쁘다.** 경락가 양파는 모델을 쓰지 말고
현재가 기준으로 판단할 것.

### 소매가 (매도 판단) — feature 24

baseline 0.1056 · 모델 0.0884 · **+16.2%**

| 품목 | baseline | 모델 | 개선율 | 방향정확도 |
|---|---|---|---|---|
| **배추** | 0.1287 | 0.1012 | **+21.3%** | 63.3% |
| **양파** | 0.0752 | 0.0665 | **+11.6%** | **66.2%** |
| 무 | 0.0896 | 0.0844 | +5.8% | 61.7% |

**양파가 경락가에서는 −1.2% 인데 소매가에서는 +11.6%** 다.
매입 판단은 어렵지만 매도 판단은 잘 맞는다는 뜻이다.

## 왜 feature 를 줄였더니 좋아졌나

### 경제 지표 (세 타겟 공통)

`m2_growth_rt` · `epu_idx` · `ppi_idx` 는 월·분기 단위로 갱신된다.
일별 예측에서는 같은 값이 한 달간 반복되므로 실질 정보가 없고,
모델이 이를 **시점 식별자로 오용**해 특정 시기를 외우게 된다.

> 선행연구(윤민정 외, 2024)는 경제 변수가 RMSE 를 1~4% 개선한다고
> 보고했으나 우리는 반대다. 리드타임(1일 vs 1~18일)과 모델 구조
> (GRU 는 시퀀스로 변화를 보지만 트리는 값 자체로 분기) 차이로 보인다.

### 주산지 기상 (소매가만)

소매가는 유통 마진이 두껍게 완충해 **산지 작황의 영향이 희석**된다.
소매가를 움직이는 것은 소비자 수요이며, `holiday_remain_d` 가
이미 그 역할을 한다(소매 모델 importance 2위, 11.2%).

산지 기상 7개 컬럼이 노이즈로 작용했다.

**경락가·중도매가에서는 기상이 여전히 기여 방향(손실 +0.0011~0.0018)이다.**
타겟에 따라 같은 feature 의 가치가 달라진다는 것이 이번 실험의 발견이다.
