| 항목 | 값 |
|---|---|
| 품목 | 배추 · 양파 · 무 (마늘 제외) |
| 학습 | 2017-01-02 ~ 2022-12-30 · 고유 기준일 **1,475** |


**마늘 제외 사유**: 피마늘/깐마늘 구분 미확정. 경락가 결측 11%(타 품목 1%),

## 5. 핵심 발견

### 유통 단계가 올라갈수록 예측이 쉬워진다

| 단계 | baseline | 이유 |
|---|---|---|
| 경락가 | 0.1864 | 매일 경매로 결정. 변동이 가장 큼 |
| 중도매가 | 0.1496 | 중도매인이 마진으로 완충 |
| 소매가 | 0.1185 | 유통 마진이 더 두껍게 완충 |

**우리가 매입 판단에 써야 하는 경락가가 가장 어렵다.**

### 매도 예측이 매입보다 정확하다

```
[매입] 경락가   +6.8%   LT18 +9.1%   방향 59.2%
[매도] 소매가   +9.8%   LT18 +18.4%  방향 65.8%
```

"언제 팔까"는 잘 맞추고 "언제 살까"는 상대적으로 어렵다.

### 리드타임 패턴이 세 모델 모두 동일하다

```
LT1~3   baseline 보다 나쁨      어제 가격이 이미 정답
LT2~4   역전 지점
LT18    최고 개선
```

짧은 미래는 가격 관성이 지배하고, 먼 미래는 기상·수급 정보가 작동한다는
설계 가설이 세 타겟 모두에서 확인됐다.

### 변동기에서 더 잘한다

| 타겟 | 평상시 | 변동기 |
|---|---|---|
| 경락가 | +6.2% | +11.3% |
| 중도매가 | +5.9% | +11.0% |
| 소매가 | +6.6% | **+26.4%** |

평상시에는 예측이 크게 필요하지 않고 급변할 때 필요하므로
**실용적으로 유리한 방향**이다.

### 매입 (경락가)

## 7. 한계와 남은 과제

### 한계

**유효 표본 부족.** 고유 기준일 1,475개다. 행수 79,614 는 리드타임 18배
복제이므로 착시다.

**소매가 `best_iter` 불안정.** 356 / 1033 / 666 으로 3배 차이가 난다.
조기 종료가 안정적으로 작동하지 않는다. 시드 표준편차는 작아 결과 자체는
신뢰할 수 있으나, 학습률 인하(0.03 → 0.01)나 정규화 강화를 검토할 것.

**통합 지표는 참고용.** 품목별 가격 수준이 다르면 분모가 큰 품목이 지배한다.
반드시 품목별로 판단할 것.

### 남은 과제
