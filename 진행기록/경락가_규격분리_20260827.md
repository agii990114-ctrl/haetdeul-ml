# 경락가 타겟 규격 분리 — 2026-08-27

**타겟 자체가 잘못돼 있었습니다.** 배추 경락가는 자기상관 0.085 로 사실상
백색잡음이었고, 그걸 상대로 1년 넘게 모델을 다듬고 있었습니다.

```
배추 경락가 ACF(1)   0.085  →  0.901
경락가 개선율        배추 −7.8% → +2.3%/+21.7%   양파 −7.7% → +10.5%/+8.6%
```

**처음으로 세 품목·두 폴드 모두 양수입니다.**

## 1. 어떻게 찾았나

발견 경로가 길었습니다. 결과보다 이 과정이 남길 값어치가 있습니다.

1. **매입 파트가 상한가·하한가를 요청** → 우리 밴드를 점검
2. 밴드 폭이 배추 0.65 로 유독 넓음 → 원인을 파다가
3. **일중 `max` 가 19,900원/kg** — 평균 939원의 21배. 이상함
4. 사용자가 가락시장 홈페이지 데이터를 제공 → **우리 DB 와 등급 순서가 반대**
5. 우리 DB 는 배추 815일 중 **737일에서 특등급이 상품보다 쌈**
6. 원본 API 를 직접 호출 → **거래 건별이고 포장 규격이 있음**
7. 규격별로 갈라보니 **하루치에 15개 상품이 섞여 있었음**

**"이상한 숫자를 그냥 넘기지 않은 것"** 이 전부였습니다. `max 19,900` 은
2015년부터 계속 있었지만 아무도 묻지 않았습니다.

## 2. 무엇이 문제였나

원천 API(`katOrigin/trades`)는 **거래 건별**이고 포장 규격마다 가격이 다릅니다.
그런데 수집기가 (날짜·시장·품목·등급)으로 뭉쳐 저장하면서 **서로 다른 상품을
한 평균에 섞었습니다.**

가락 배추 특등급 2026-08-03 하루치:

| 포장 | kg | 원/kg | 물량 |
|---|---|---|---|
| **그물망** | **10** | **711** | **322,940kg (79%)** |
| 상자 | 8 | 1,721 | 35,640 |
| 상자 | 4 | 5,841 | 3,744 |
| 상자 | 1 | **11,224** | 2,278 |
| … 11종 더 | | | |
| **[가중평균 = 우리 타겟]** | | **939** | 410,960 |

소분류도 섞였습니다 — **쌈배추 156건 · 수입배추 · 생채용**이 "배추"에 들어옵니다.

### 이미 kg 단가인데도 31.6배 차이

"1kg 단위로 통일하면 되지 않나" 는 답이 아닙니다. **이미 전부 원/kg 입니다.**

```
배추 특등급 포장중량별 원/kg
   1kg 포장  10,913      8kg 포장   1,729
   4kg 포장   4,468     10kg 포장     659   ← 물량 89%
```

kg 로 나누는 건 **양을 맞추는 것**이지 상품을 맞추는 게 아닙니다.
우유 1L 1,000원과 200mL 800원을 "L당" 으로 평균 내는 것과 같습니다.

## 3. 규격을 두 번 잘못 잡았다

한 번에 못 맞췄습니다. 두 번의 실패가 남길 값어치가 있습니다.

### 실패 ① "같은 중량이면 같은 상품"

처음엔 포장 형태를 열어두고 중량만 걸었습니다. 하루치로 그물망 731원 vs
파렛트 873원이 비슷해 보였기 때문입니다.

5년치로 재보니 틀렸습니다.

```
배추 10kg 안에서   그물망 824 · 파렛트 943 · 상자 1,115 · 비닐봉지 3,071원
10kg 전체  ACF(1) 0.484        그물망만  ACF(1) 0.908
```

**비닐봉지 10kg 은 그물망의 3.7배**입니다. 같은 중량이라도 다른 상품입니다.

### 실패 ② 포장 형태를 품목 공통으로 묶음

형태를 `그물망·상자·파렛트` 로 한정했더니 배추가 0.928 → **0.513** 으로
떨어졌습니다. 무 때문에 넣은 `상자` 가 배추에서는 소포장 계열이었습니다.

**포장 형태는 품목마다 다릅니다.**

### 확정

| 품목 | 포장 형태 | 중량 | ACF(1) | 물량 비중 |
|---|---|---|---|---|
| 배추 | 그물망 · 파렛트 | 10kg | 0.901 | 94% |
| 무 | 상자 · 파렛트 | 18kg(~2017) → 20kg | 0.928 | 76% |
| 양파 | 그물망 · 파렛트 | 15kg | 0.979 | 71% |

**무는 2018년에 포장 표준이 바뀌었습니다.** 2017 은 18kg 227일 / 20kg 63일,
2018부터는 20kg 가 300일대입니다. 연도로 갈라야 양쪽 다 온전합니다 —
겹쳐 쓰면 2018 이후의 띄엄띄엄한 18kg 잔여 거래가 섞여 ACF 가 0.373 이 됩니다.

**등급은 특(11) 유지.** 매입 파트가 "상 등급"을 요청했으나 **가락 물량의 98%가
특등급**이고, 양파 상 등급은 1년에 30~54일만 거래돼 시리즈를 만들 수 없습니다.
배추 상 등급은 규격이 상자 8kg 로 달라 가격이 두 배입니다(1,411 vs 729원).

## 4. 성능 — 처음으로 전부 양수

경락가 · 학습 2017~ · 시드 5 · 게이트 LT<3 · **baseline 은 경락가 계열 4종 중 최강**

| 품목 | 폴드A (검증2023) | 폴드B (검증2022) |
|---|---|---|
| 배추 | **+2.3%** | **+21.7%** |
| 무 | **+3.2%** | **+15.1%** |
| 양파 | **+10.5%** | **+8.6%** |

이전 (혼합 타겟, 같은 조건):

| 품목 | 폴드A |
|---|---|
| 배추 | **−7.8%** |
| 무 | +1.2% |
| 양파 | **−7.7%** |

**양파가 가장 크게 뒤집혔습니다** (−7.7% → +10.5%). 자기상관은 0.974→0.979 로
거의 안 변했는데 예측 성능은 크게 달라졌습니다. **ACF 만으로는 안 보이는
피해가 있었다**는 뜻입니다.

**배추는 폴드 간 격차가 큽니다** (+2.3% vs +21.7%). 2022 는 태풍이 든 해라
모델이 값어치를 내고 2023 은 조용해 이동평균 수준입니다. 어제 확인한
"폴드 B 는 충격 폴드" 패턴 그대로입니다.

### ⚠ WMAPE 절대값은 이전과 비교하면 안 됩니다

0.1801 → 0.2127 로 올랐지만 **나빠진 게 아니라 타겟이 바뀐 것**입니다.
혼합 타겟은 소포장 고가가 섞여 평균이 939원이었고 지금은 진짜 시장가 777원
이라 분모가 작습니다. baseline 도 함께 어려워졌습니다(배추 어제값 0.2557 →
0.3078). 그런데 모델이 그걸 넘어섰습니다.

## 6. 곁가지로 나온 것

### `run_batch.py` 재시도 층

같은 날 두 번 겪었습니다.

```
09:00  배치 predict 실패   connection timeout    → 9시간 예측 없음
11:5x  수집 50분치 날아감   IncompleteRead        → 캐시 덕에 66초로 복구
```

둘 다 일시적 오류라 한 번만 다시 했으면 끝날 일이었습니다.

**작업 스케줄러의 "실패 시 다시 시작" 은 이걸 못 잡습니다.** 그 설정은 작업이
*시작되지 못했을 때* 동작하고, 프로그램이 0 아닌 종료 코드로 끝나는 것은
"정상 완료" 로 처리합니다. `RestartCount 2` 를 걸어뒀는데도 08-27 09:00
실패에서 재시작이 일어나지 않은 것이 증거입니다.

그래서 `run()` 안에 넣었습니다. 목록에 있는 문구(timeout·connection reset·
IncompleteRead·5xx 등)만 재시도하고, 단계당 2회 · 실행당 3회 상한입니다.
`rebuild` 는 TRUNCATE 로 시작하므로 대상에서 제외했습니다.

## 7. 남은 것

1. **앵커 α 재판정** — 어제 α=0.6 을 채택했으나 혼합 타겟 위에서 잰 값이라
   무효. 새 타겟에서 다시 재는 중
2. **중도매가·소매가 재측정** — `auc_prc_lag1`·`auc_whsl_ratio_lag1` 이 그쪽
   feature 로 들어가 값이 바뀌었습니다
3. **2015~2016 재수집 + 학습량 곡선 재판정** — "2017 시작" 판정도 혼합 타겟
   위에서 한 것입니다. **잡음을 상대로 "데이터를 얼마나 넣어야 하나" 를 재면
   의미가 없습니다.** 진짜 가격 계열에서는 결론이 달라질 수 있습니다
4. **운영 모델 재학습 + 밴드 재생성** — 모델과 밴드는 짝입니다
5. **`ref_prediction_quality` 재판정** — 차단 조합이 달라집니다
6. **반입량 vs 경매 거래량 비교** — `arr_qty_lag1`(반입)과 `auc_vol_lag1`(경매
   낙찰)이 둘 다 feature 인데 서로 얼마나 다른지 안 봤습니다. "반입은 됐는데
   경매로 안 팔린 비율" 이 새 신호일 수 있습니다

## 8. 남길 교훈

**이상한 숫자를 그냥 넘기지 않는 것.** `max 19,900원/kg` 은 2015년부터 있었고
어떤 검증 쿼리도 이걸 보지 않았습니다. 등급 역전(특<상)도 90% 의 날에
일어나고 있었는데 아무도 묻지 않았습니다.

**알고 나면 규칙으로 만들 수 있습니다.**

```
등급 순서 검사      특 ≥ 상 ≥ 중 인가         → 배추 90% 위반
일중 분산 검사      max/min 이 10배 넘는가     → 132배
계열 건전성 검사    ACF(1) 이 0.3 미만인가     → 0.085
```

이런 "당연히 성립해야 하는 것" 을 주기적으로 훑는 층이 있어야 합니다.
데이터 품질 자동 감시(`Q-01`)에 이 셋을 넣을 것.
