## 1. 실험 조건

| 항목 | 값 |
|---|---|
| **타겟** | `target_auc_prc` (경락가, 원/kg) |
| **앵커** | `auc_prc_lag1` |
| 타겟 변환 | 앵커 대비 로그비율 `y = log(target / anchor)` |
| **품목** | 배추 · 양파 · 무 (마늘 제외) |
| **학습** | 2019-01-02 ~ 2022-12-30 · 53,064행 · 고유 기준일 **988** |
| **검증** | 2023-01-02 ~ 2025-12-30 · 38,565행 · 고유 기준일 730 |
| feature | 34개 |
| 시드 | 42 · 43 · 44 (3회 반복) |
| 모델 | LightGBM (objective=regression_l1) |

```powershell
python train.py crop_price_train_202608211709.csv --target auc \
  --train-start 2019-01-01 --train-end 2022-12-31
```

**마늘 제외 사유**: 피마늘/깐마늘 구분이 확정되지 않았고, 경락가 결측이
11.0%(다른 품목 0.9~1.0%)로 높다. 반입량이 일평균 28t 으로 다른 품목의 4%
수준이라 경매가 열리지 않는 날이 많은 것으로 보인다.

**`crop_area_yoy_rt` 제외 사유**: 결측 75%. 품목별로는 양파 1.4%,
나머지 3품목 100% 로 사실상 "양파에만 있는 feature" 가 되어
모델이 품목 식별자로 오용할 위험이 있다.

## 3. 품목별 성능 ★

**통합 지표만 보면 안 된다.** 품목마다 문제의 성격이 완전히 다르다.

| 품목 | baseline | 모델 | 개선율 | 방향정확도 | 검증 행수 |
|---|---|---|---|---|---|
| **배추** | 0.2618 | 0.2358 | **+9.9%** | **61.1%** | 12,879 |
| 무 | 0.2188 | 0.2103 | +3.9% | 56.8% | 12,807 |
| **양파** | 0.1008 | 0.0993 | **+1.4%** | 55.5% | 12,879 |

### 해석

**배추가 가장 잘 맞는다.** 주산지 매핑을 실측 데이터로 4개월 수정한 작업이
여기서 나타난 것으로 보인다. 방향정확도 61.1% 는 3번 중 2번 등락 방향을
맞춘다는 뜻이다.

**양파는 개선 여지가 거의 없다.** baseline 이 0.1008 로 이미 낮다.
양파 가격은 68.5% 의 날에 전일과 동일한 값이라(저장성 품목) 예측 문제로서
쉬운 동시에 모델이 개입할 공간도 좁다.

다만 사업 관점에서 이것이 나쁜 결과는 아니다. **양파는 예측 오차 자체가
작으므로(WMAPE 0.0993) 매입 계획을 안정적으로 세울 수 있다.**
배추는 변동이 크지만 모델이 그 변동을 상당 부분 잡아낸다.

짧은 리드타임은 "어제 가격"이 이미 정답에 가까워 모델이 개입할 여지가 없고,

설계 단계의 가설이 데이터로 확인됐다.

**저장 트레이딩은 긴 리드타임이 중요하므로 이 패턴이 유리하다.**

### 품목 × 리드타임 최적 구간

| 품목 | 최고 개선 | 최저 | 방향정확도 최고 |
|---|---|---|---|
| 배추 | **LT9 (+12.9%)** | LT1 (−2.1%) | **LT9 (63.4%)** |

**품목마다 유효 구간이 다르다.** 배추는 9영업일(약 2주) 전 판단이 가장

매매 시점 설계 시 품목별로 다르게 잡아야 한다.

```
auc_prc_lag1              17.6%   경락가 앵커
auc_whsl_ratio_lag1        9.0%   유통 마진 배수  ★

rtl_prc_lag1               4.5%   소매가
prod_area_gdd_sum30        4.4%   적산온도
whsl_prc_avg14             4.1%
prod_area_stn_nm           4.1%   주산지 관측소
m2_growth_rt               3.4%
ppi_idx                    3.4%
prod_area_rain_sum30       3.1%
arr_qty_avg7               2.7%
prod_area_clim_temp_avg10  2.1%
```

### 확인된 것 두 가지

**`auc_whsl_ratio_lag1`(유통 마진 배수)이 2위다.**
경락가 대비 중도매가의 배수를 feature 로 추가한 것인데 실제로 기여했다.
"급등기에 중도매인이 마진을 줄여 흡수하므로 배수 축소 자체가 시장 압력
신호" 라는 가설이 데이터로 지지됐다.

**주산지 기상이 합계 17.0%** (기온 5.3 + GDD 4.4 + 관측소 4.1 + 강수 3.1).
매핑을 실측으로 수정한 작업의 가치가 수치로 확인된다.

## 6. 구간별 성능

| 구간 | 모델 | baseline | 개선율 |
|---|---|---|---|
| 평상시 | 0.1678 | 0.1786 | +6.0% |

## 7. 남은 과제

### 실험

- [ ] **중도매가·소매가 모델** 동일 조건으로 학습
      사업 모델상 매입(경락가)과 매도(소매가)가 모두 필요하다
- [ ] **학습 시작일 재탐색** — 2019 고정은 이전 조건(중도매가·2품목)에서
      나온 최적점이다. 타겟과 품목이 바뀌었으므로 다시 그려야 한다
- [ ] **A0~A7 ablation** — feature 그룹별 기여도 미측정

### 데이터

- [ ] 마늘 피마늘/깐마늘 구분 확정
      경락가 API 응답에 `gds_sclsf_cd`(소분류)와 `corp_gds_vrty_nm`(품종명)이
      있으나 현재 수집기가 요청·저장하지 않는다
- [ ] 깐마늘 소매가를 학습 테이블에 반영
      `veg_daily_price_raw` 적재는 완료(item_cd=258, 208,125행)했으나
      SQL 필터가 `item_nm IN ('배추','양파','무','마늘')` 이라 걸리지 않는다
- [ ] KREI 재배면적 결측 해소 — 배추·무·마늘 100% 결측

### 구조

- [ ] 유효 표본이 여전히 부족하다 (고유 기준일 988)
      학습 구간을 넓히거나, 리드타임 복제로 인한 표본 착시를 감안한
      평가 방식을 검토할 것
