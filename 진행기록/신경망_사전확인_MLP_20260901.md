# 신경망 사전 확인 — "왜 딥러닝을 안 썼나" 에 대한 실측

작성 2026-09-01 17:46:31 · 원가 캣쳐 ML 파트

---

## 결론 먼저

**같은 입력을 신경망(MLP)에 주면 단순 평균에도 크게 집니다.**
6개 조합(3가지 크기 × 2폴드) **전부** 그렇습니다.

```
LightGBM(운영)   0.1670 / 0.1968      앵커 대비  +3.5% / +6.1%
앵커(단순 평균)    0.1730 / 0.2096
MLP 최선          0.2468 / 0.2651     앵커 대비 −42.6% / −26.5%
```

**그래서 TFT(트랜스포머) 착수를 미룹니다.** 2GB 설치와 며칠 작업을 할
근거가 약합니다.

**★ 다만 이것이 "TFT 도 진다" 를 증명하지는 않습니다.** 아래 6장에서
무엇이 증명됐고 무엇이 안 됐는지 나눠 적습니다.

---

## 1. 왜 했나 — TFT 설치 전에 싸게 묻기

`진행계획/2026-09-01_134706_모델비교_계획.md` 의 ② TFT 를 하려면
`torch` 를 깔아야 하는데 **2GB 가 넘고 며칠 작업**입니다.

그 전에 **"신경망이라는 방식 자체가 우리 자료에서 근처라도 가나"** 를
물었습니다. `sklearn` 은 이미 깔려 있어 **30분**이면 끝납니다.

```
근처도 못 감  →  설치 전에 안다. 비용을 안 낸다
근처까지 감   →  구조를 더 준 TFT 는 볼 가치가 생긴다
```

---

## 2. 무엇을 쟀나 — **TFT 가 아니라 MLP 입니다**

**MLP**(다층 퍼셉트론)는 신경망의 가장 기본형입니다.
입력을 전부 섞어 새 값을 만들고, 그걸 또 섞기를 반복합니다.

```
입력 31개 → [256개 층] → [128개 층] → [64개 층] → 답 하나
```

**부스팅과의 차이는 "고르느냐 섞느냐" 입니다.**

```
나무(LightGBM)   "어제 가격이 800원보다 높나?" — 하나를 골라 갈라선다
그물(MLP)        31개를 전부 조금씩 섞어 새 값을 만든다
```

---

## 3. 공정하게 재려고 맞춘 것

신경망은 부스팅과 달리 **전처리 없이는 아예 못 배웁니다.**
그래서 세 가지를 했고, **전부 신경망에 유리한 쪽으로만** 했습니다.

| 문제 | 왜 문제인가 | 처리 |
|---|---|---|
| 값 크기가 다름 | 가격 4,800과 기온 15를 섞으면 **가격이 계산을 지배** | 표준화 |
| 빈 값 | 섞을 수가 없음 | 중앙값으로 채움 |
| 글자(배추/무/양파) | 숫자가 아니라 못 섞음 | one-hot 으로 펼침 (31개 → 44개) |

**기준값(중앙값·표준편차)은 학습 자료에서만 잡았습니다.** 검증 자료로
잡으면 미래를 훔쳐보는 것이 되어 검증에서만 잘 나옵니다.

**나머지는 전부 같습니다** — feature 31개 · 앵커 변환 · 학습 구간 ·
폴드 · LT 게이트 3 · baseline.

조기 종료를 켰습니다 (학습 자료의 15% 로 15회 개선이 없으면 중단).
**신경망이 과적합으로 무너지지 않게 하기 위한 배려**입니다.

## 4. 결과

**경락가 · 시드 3개 · LightGBM 은 운영값(76그루)**

| 모델 | 폴드 A (검증 2023) | 폴드 B (검증 2022) |
|---|---|---|
| **LightGBM (운영)** | **0.1670** (+3.5%) | **0.1968** (+6.1%) |
| *앵커 (비교 기준)* | *0.1730* | *0.2096* |
| MLP 64 | 0.2967 (−71.5%) | 0.2980 (−42.1%) |
| MLP 128,64 | 0.2771 (−60.1%) | **0.3449 (−64.5%)** |
| MLP 256,128,64 | 0.2468 (−42.6%) | 0.2651 (−26.5%) |

### 세 가지가 보입니다

**① 6개 조합 전부 단순 평균에 집니다.** 제일 좋은 것이 −26.5% 입니다.

**② 크기와 성적이 일관되게 움직이지 않습니다.**

```
폴드 A   64 → 128,64 → 256,128,64      0.2967 → 0.2771 → 0.2468   좋아짐
폴드 B   64 → 128,64 → 256,128,64      0.2980 → 0.3449 → 0.2651   들쭉날쭉
```

폴드 B 에서는 **중간 크기가 제일 나쁩니다.** "키우면 좋아진다" 는 규칙조차
성립하지 않습니다.

**③ 답이 들쭉날쭉합니다.** 시드 편차가 LightGBM 의 5~80배입니다.

```
LightGBM   0.0002 ~ 0.0004
MLP        0.0019 ~ 0.0327
```

**같은 자료로 다시 돌리면 답이 크게 달라집니다.**
배우고 있다기보다 헤매고 있다는 뜻입니다.

### 비용

```
LightGBM        1~2초
MLP 256,128,64  809~921초       약 500배
```

## 5. 왜 이런가 — **표본이 얇습니다**

```
실질 표본   고유 기준일 1,475개 (2017~2022)
```

행이 78,119개로 보이지만 **한 기준일이 3품목 × 18리드타임 = 54행으로
복제**되므로 실질 표본은 1,475개입니다.

**같은 날 부스팅에서도 같은 신호가 나왔습니다.**

```
LightGBM   50그루   0.1665
           1200그루  0.1855      ← 키우니 11% 나빠짐
```

**이 자료는 큰 모델을 감당할 표본이 없습니다.** MLP 256,128,64 는
LightGBM 1200그루보다도 큰 모델입니다.

> 문제집 100쪽으로 공부하는데 참고서를 1,000쪽짜리로 바꾸는 것과 같습니다.
> 참고서가 좋아도 풀 문제가 없으면 소용이 없습니다.

## 6. ★ 무엇이 증명됐고 무엇이 안 됐나

**증명된 것**

```
같은 입력을 그냥 신경망에 주면 단순 평균에도 크게 진다 (6/6 조합)
```

**증명 안 된 것**

```
TFT 도 그럴 것이다
```

**TFT 는 MLP 와 세 가지가 다릅니다.**

| | MLP (오늘 잰 것) | TFT (안 잰 것) |
|---|---|---|
| 정보 받는 법 | 31개를 **한 줄로 뭉쳐** 받음 | **세 종류로 나눠** 받음 — 안 변하는 것(품목) · 미리 아는 미래(요일·명절까지 며칠) · 과거 관측(가격·날씨) |
| 어디를 보나 | 늘 같은 방식으로 섞음 | **상황에 따라 볼 곳을 고름** (어텐션) |
| 구간 | 못 냄 | **상한·하한을 원래부터 냄** |

**두 번째 줄이 우리 문제에서 특히 의미가 있습니다.** "1월 5일은 월요일" 은
지금 확실히 아는 미래이고, "1월 5일 산지 기온" 은 지금 모릅니다.
**성격이 다른데 우리는 지금 같은 줄에 뭉쳐 넣고 있습니다.**

**그러니 이 문서는 "TFT 를 하지 말자" 가 아니라
"지금 2GB 설치와 며칠 작업을 할 근거가 약하다" 입니다.**

---

## 7. 그래서 어떻게 하나

### TFT — 미룹니다 (백로그 [M-20])

**재개 조건**을 적어둡니다. 아래 중 하나라도 생기면 다시 봅니다.

```
· 표본이 늘어난다 (다른 시장·다른 품목을 넣어 실질 기준일을 키운다)
· 8/31 에 찾은 "입력 28개 중 17개가 한 기준일 안에서 같은 값" 이 풀린다
· 발표·심사에서 "트랜스포머는 봤나" 에 답이 필요해진다
```

### GRU · LSTM ([M-09]) — 이 결과로 일부 대체합니다

**"왜 딥러닝을 안 썼나" 에 대한 답은 이미 나왔습니다.**

**★ 다만 발표 자료에는 정확히 써야 합니다.**

```
쓸 수 있는 말   "기본형 신경망(MLP)으로 재봤고 단순 평균에도 크게 졌다"
쓰면 안 되는 말  "GRU·LSTM 으로 재봤다"      ← 안 쟀습니다
                "딥러닝은 이 문제에 안 된다"  ← 한 종류만 쟀습니다
```
