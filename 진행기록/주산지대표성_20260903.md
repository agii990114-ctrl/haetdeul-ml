## 한 줄로

**채택하지 않습니다. 폴드 C(검증 2021)가 부호를 뒤집었습니다 —
이득이 전부 폴드 B(태풍이 든 해) 것이었습니다.**

두 폴드로는 통과했고 새 시드로 재현까지 됐지만, **충격이 없는 해를
넣으니 사라졌습니다.** 그리고 가설이 말한 자리(경락가)에서는
애초에 아무 효과가 없었습니다.

```
폴드 A (2023)   +0.0003
폴드 B (2022)   +0.0029    <- 태풍 힌남노가 든 해
폴드 C (2021)   -0.0006    <- 충격 없는 해. 부호가 반대
```

## 1. 전제는 실측으로 확인됐습니다

우리는 품목×월로 **주산지 관측소 하나**를 골라 그 기상을 씁니다.
그런데 1위 산지가 물량의 절반도 대표하지 못하는 날이 많습니다.

| 품목 | 평균 비중 | 50% 미만인 날 |
|---|---|---|
| 양파 | 43.3% | **2,023일 (74.1%)** |
| 배추 | 52.9% | 1,324일 (48.3%) |
| 무 | 62.0% | 1,004일 (36.6%) |

월별로도 크게 흔들립니다.

```
무     3월 90%  ->  11월 30%
배추  12월 83%  ->   6월 32%
양파   5월 74%  ->   1월 32%
```

**매핑을 고쳐도 안 없어지는 문제가 맞습니다.** 1위가 40%뿐이면 어느
관측소를 골라도 나머지 60%를 못 봅니다.

## 2. 무엇을 넣었나

**(품목 × 월 × 순) 평균 비중** 을 feature 로 넣었습니다.

**★ 실측이 아니라 프로파일입니다.** 예측 대상일은 아직 안 온 날이라 그날
비중을 알 수 없습니다. **프로파일은 폴드마다 학습 구간 자료로만** 만들어
답을 미리 보지 않게 했습니다 (학사일정에서 쓴 방식 — 5.10절).

```
keep    현행 그대로                        <- 기준
share   + prod_area_top1_share
both    + 비중 · 비중x주산지기온(곱)        "믿을 만할 때만 기온을 보라"
```

`exp_top1_share.py` · 상세 `실험결과/주산지대표성_20260903.txt`

## 3. 결과 — 24칸 중 하나

**경락가·중도매가는 전부 판정 불가**였습니다.
**소매가 배추에서만** 나왔습니다.

| 시드 | 폴드 A | 폴드 B | 합산 | 필요 | 판정 |
|---|---|---|---|---|---|
| 62~81 | +0.0003 | +0.0029 | +0.0032 | 0.0024 | ★ 넣는 게 낫다 |
| **82~101** | **+0.0004** | **+0.0035** | **+0.0040** | 0.0027 | **★ 넣는 게 낫다** |

**겹치지 않는 시드 두 벌에서 재현됐습니다.**

```
폴드 A (2023)   0.1107 -> 0.1104   +0.27%
폴드 B (2022)   0.1408 -> 0.1379   +2.08%
```

> **`share` 와 `both` 가 소매가에서 값이 똑같습니다.** 소매가에는
> `prod_area_temp_avg_lag1` 이 없어서 곱을 만들 수 없기 때문입니다.
> 코드가 그 경우 `both` 를 `share` 와 같게 둡니다.

## 4. ★ 가설이 틀렸습니다 — 반대 자리에서 듣습니다

백로그의 근거는 이것이었습니다.

> "1위 산지 비중이 낮은 구간은 그 산지 기상이 전체를 대표하지 못한다"

**그러면 주산지 기상을 쓰는 타겟에서 들어야 합니다. 반대로 나왔습니다.**

| 타겟 | 주산지 기상 feature | 결과 |
|---|---|---|
| 경락가 | 5개 있음 (기온·강수7/30·생육온도·평년) | **판정 불가** |
| 중도매가 | 있음 | 판정 불가 |
| **소매가** | **없음** (`market_temp_avg_lag1` 뿐) | **★ 배추에서 채택** |

**소매가에는 덜 믿을 기상이 없습니다.** 5.3절에서 소매가는 주산지 기상을
빼는 게 낫다고 판정해 이미 제외했습니다.

### 그럼 무엇으로 듣는가

이 값은 **(월 × 순) 36칸짜리 품목별 곡선**입니다. 소매가 모델에게는
**"이 품목의 공급이 계절에 따라 얼마나 몰리나" 를 알려주는 곡선**입니다.

**M-07 에서 `월`(12칸 · 품목 공통)을 넣었을 때는 안 들었습니다.**
차이는 **품목마다 다른 곡선**이라는 점으로 보입니다.

> **다만 이건 추정입니다.** "왜" 를 확인하지 못했습니다.
> 프로파일 흔들림으로는 설명이 안 됩니다 — 오히려 무가 더 큽니다
> (최대−최소 무 71%p · 배추 62%p · 양파 49%p).

## 5. ★ 이득이 폴드 B 에 몰려 있습니다 — 다섯 번째입니다

```
폴드 A (검증 2023)   +0.27%
폴드 B (검증 2022)   +2.08%     <- 태풍 힌남노(2022-09-06)가 든 해
```

**공급이 흔들린 해에 "지금 산지가 얼마나 몰려 있나" 가 도움이 됩니다.**
말이 되는 이야기입니다 — 산지가 한 곳에 몰려 있을수록 그 지역 사고가
전체를 흔듭니다.

**규칙(2폴드 부호 일치 · 편차×2)은 통과하지만, 실질은 "충격기에 듣는
feature"** 입니다. 두 시드 벌 모두 폴드 A 는 +0.0003~+0.0004 로 사실상 0 입니다.

폴드 B 가 다른 사례 목록 (CLAUDE.md 5.10 에 이어서):

```
1  학사일정        폴드 B 만 음수
2  volume 그룹     폴드 B 만 음수
3  주산지 기상 제거  폴드 B 만 크게 나빠짐  <- 여기서 원인(힌남노)을 찾음
4  M-07 month      폴드 B 에만 이득
5  M-06 이 건       폴드 B 에만 이득
```

## 6. 반영 — 보류합니다

**채택 조건은 통과했지만 지금 넣지 않습니다.**

```
1  소매가는 우리 세 모델 중 유일하게 봉인 개봉에서 9칸 전부 양수였다.
   가장 보수적으로 다룬다
2  이득의 실체가 "충격기에 듣는다" 인데 폴드 하나로 본 것이다
3  가격이 바뀌는 변경이고, 매입 파트가 지금 밴드 전후 대조 중이다.
   명절 feature 와 같이 묶어야 저쪽이 대조를 여러 번 안 한다
```

**다음에 볼 것** — 폴드 C(검증 2021)로 한 번 더. 충격이 없는 해에서도
양수면 "충격기 전용" 이 아니라는 뜻입니다.

## 7. 곁들여 — 분위수 q 값 재판정 (마늘 제외 조건)

오늘 찾은 **실험 도구 사고**(`진행기록/실험도구_마늘혼입_20260903.md`)
때문에 운영에 들어간 밴드의 q 값을 다시 쟀습니다.

**결과 — 전부 유지됩니다.**

| 타겟 | 품목 | 운영 q | 폴드A | 폴드B | 목표 80% |
|---|---|---|---|---|---|
| 경락 | 배추 | 0.03 | 84.2 | 80.6 | ✓ |
| | 무 | 0.03 | 88.8 | 85.4 | ✓ |
| | 양파 | **0.02** | 82.9 | 84.8 | ✓ |
| 중도매 | 배추 | 0.03 | 80.9 | 82.1 | ✓ |
| | 무 | **0.02** | 83.5 | 90.0 | ✓ |
| | 양파 | 0.03 | 81.0 | 85.1 | ✓ |

**품목마다 다른 q 를 쓰는 이유도 그대로 확인됐습니다.**

```
양파 경락가를 q03 으로 두면   74.7%   미달
무 중도매를  q03 으로 두면   78.6%   미달
```

옛 기록(5.11절)과 견주면 소수점 첫째 자리까지 거의 같습니다
(예: 경락 배추 84.2/80.4 → 84.2/80.6). **분위수는 검증 구간에서
보정되는 값이라 학습 자료 구성에 덜 흔들립니다.**

**운영에 들어간 밴드는 확인됐습니다.**
