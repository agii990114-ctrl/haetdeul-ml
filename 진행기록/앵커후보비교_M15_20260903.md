# 앵커를 잘 골랐는가 [M-15] — 현행이 최선. 그리고 2폴드 규칙이 두 번 뚫렸다

작성 2026-09-03 15:43:57 · 햇들농산 ML 파트 (지환) · 백로그 [M-15]

---

## 한 줄로

**앵커 후보 여섯 중 현행을 이긴 것이 없습니다.**
그런데 이 실험에서 **더 중요한 게 나왔습니다** —
**오늘 2폴드를 통과한 후보 둘이 모두 폴드 C 에서 뒤집혔습니다.**

---

## 1. 왜 했나

우리 모델은 **앵커에서 얼마나 움직일지**를 배웁니다.

```
학습   y = log(정답 / 앵커)
예측   예측가 = 앵커 x exp(모델 출력)
```

**앵커가 곧 출발점이고 동시에 정의상 baseline** 입니다 — 모델이 0을 내면
앵커가 그대로 나갑니다. **그런데 "그 앵커가 최선인가" 를 한 번도 안 물었습니다**
(CLAUDE.md 11절 · 백로그 M-15).

**오늘 feature 실험 셋(M-12 · M-07 · M-06)이 전부 "변경 없음" 으로 끝났습니다.
이득이 feature 에 없다면 토대를 봐야 합니다.**

---

## 2. 무엇을 견줬나

```
now      현행 수축앵커  a x 어제값 + (1-a) x 7일평균  (경락 0.4 · 중도매 0.8 · 소매 1.0)
lag1     어제값만
avg7     최근 7일 평균만
avg14    최근 14일 평균만
prev_yr  작년 같은 시기
mix_yr   현행 x 0.8 + 작년같은시기 x 0.2
```

### 공정하게 재려고 두 가지를 맞췄습니다

**① 여섯 후보가 모두 값이 있는 행에서만** 견줬습니다. `prev_yr` 은 첫 해가
비어서, 안 맞추면 쉬운 행만 남은 후보가 유리해집니다.

**② 앵커에 쓰는 가격 컬럼은 여섯 후보 모두 feature 에서 뺐습니다.**
안 빼면 정답을 두 번 주는 셈이고, 후보마다 재료가 달라져 무엇 때문에
좋아졌는지 못 가립니다.

> **코드가 맞다는 확인** — 소매가는 α=1.0 이라 현행이 곧 `lag1` 입니다.
> 실제로 `lag1` 이 **정확히 +0.0000** 으로 나왔습니다.

`exp_anchor_cands.py` · 상세 `실험결과/앵커후보_20260903.txt`

## 3. 결과 — 현행을 이긴 것이 없습니다

| 후보 | 결과 |
|---|---|
| `lag1` | **크게 짐** (경락 −0.03~−0.05) |
| `prev_yr` | **크게 짐** (−0.13 ~ −0.39) |
| `avg7` · `avg14` | 판정 불가 또는 현행이 나음 |
| `mix_yr` | 소매가 배추만 2폴드 통과 → **폴드 C 에서 뒤집힘** |

**`lag1` 이 크게 지는 것은 2026-08-28 수축앵커 도입이 옳았다는 확인**입니다.

### 앵커 자체의 성능 (baseline · 폴드 A)

| 타겟 | 후보 | 배추 | 무 | 양파 |
|---|---|---|---|---|
| 경락가 | **now** | **0.2292** | **0.2193** | 0.1191 |
| | lag1 | 0.2533 | 0.2361 | 0.1253 |
| | prev_yr | 0.4681 | 0.4242 | 0.3464 |
| 소매가 | **now(=lag1)** | 0.1377 | **0.1224** | **0.0621** |
| | mix_yr | **0.1193** | 0.1298 | 0.0688 |

**★ 좋은 baseline 이 좋은 앵커라는 보장이 없습니다.**
소매가 배추에서 `mix_yr` 은 **앵커 자체로는 현행보다 낫습니다**
(0.1193 vs 0.1377). 그런데 **모델을 붙이면 3폴드에서 집니다.**
앵커가 이미 정확하면 모델이 배울 것이 줄어듭니다.

## 4. ★ 이 실험의 진짜 발견 — 2폴드 규칙이 뚫린다

`mix_yr` 소매가 배추는 이렇게 나왔습니다.

```
시드 62~81   A +0.0093 · B +0.0068   합산 +0.0160 (필요 0.0035)   ★ 4.6배로 통과
시드 82~101  A +0.0101 · B +0.0073                                ★ 재현됨
폴드 C 추가  C -0.0166                                            ★ 뒤집힘
```

**A·B 가 같은 방향이고, 새 시드로 재현까지 됐는데, 폴드 C 하나가 그보다
크게 음수입니다.** 합산이 +0.0008 로 사실상 0 이 됩니다.

### 같은 날 두 번째입니다

```
M-06 share    A +0.0003 · B +0.0029 · C -0.0006    폴드 B 에 몰림
M-15 mix_yr   A +0.0101 · B +0.0073 · C -0.0166    A·B 둘 다 양수인데 뒤집힘
```

**두 번째가 더 무섭습니다.** 오늘 아침에 더한 규칙(*"폴드 B 에만 몰리면
폴드 C 를 본다"*)으로는 **이건 안 걸립니다.**

> **오늘 2폴드를 통과한 후보가 둘, 폴드 C 를 통과한 것이 0개입니다.**

---

## 5. 그래서 명절 feature 를 다시 쟀습니다 — **통과했습니다**

운영에 넣으려던 것이고 매입 파트에 사전통보까지 나갔는데,
**폴드 C 를 안 봤습니다.** 지금 확인했습니다.

| 타겟 | 품목 | 폴드A | 폴드B | **폴드C** | 합산 | 필요 | 판정 |
|---|---|---|---|---|---|---|---|
| 경락가 | **무** | +0.0025 | +0.0140 | **+0.0044** | **+0.0209** | 0.0044 | **★ 비우는 게 낫다** |
| 중도매가 | **무** | +0.0030 | +0.0064 | **+0.0029** | +0.0123 | 0.0048 | **★ 비우는 게 낫다** |
| 소매가 | **무** | +0.0018 | +0.0061 | **+0.0024** | +0.0103 | 0.0030 | **★ 비우는 게 낫다** |
| 소매가 | **배추** | −0.0018 | −0.0015 | −0.0007 | −0.0040 | 0.0025 | **★ 그대로 두는 게 낫다** |

**무는 9개 폴드-측정이 전부 양수입니다.** 새 시드(62~81)로도 재현됐습니다.

**바뀐 것 하나** — 중도매가 배추가 2폴드에서는 "손해 확정"(−0.0083)이었는데
폴드 C 에서 +0.0010 으로 갈려 **판정 불가**가 됐습니다.

### 권고는 그대로입니다

```
경락가     적용     무 +0.0209 (3폴드 전부 양수) · 배추·양파 판정 불가
중도매가    적용 안 함  무는 이득이나 배추가 판정 불가로 애매하다
소매가     적용 안 함  배추 손해가 3폴드 전부 음수로 확정
```

## 6. 규칙을 고칩니다

**오늘 아침에 더한 것** (5.7절 ③)

> 이득이 폴드 B 에만 몰리면 폴드 C 를 본다

**부족합니다. 이렇게 바꿉니다.**

> **운영에 반영할 것은 폴드 C 를 반드시 본다.**
> 2폴드 부호 일치 + 편차×2 는 **탐색용 기준**이고, **채택 기준이 아니다.**

근거 — 오늘 3폴드로 검증한 것이 셋인데 **둘이 탈락했습니다.**

```
M-06 share      2폴드 통과 · 새 시드 재현 -> 폴드 C 에서 탈락
M-15 mix_yr     2폴드 통과 · 새 시드 재현 -> 폴드 C 에서 탈락
명절 feature     2폴드 통과 · 새 시드 재현 -> 폴드 C 통과 ★
```

**하나가 살아남았고 하필 그게 운영에 넣으려던 것**이라, 규칙이 실제로
값을 했습니다 — **둘은 막고 하나는 통과시켰습니다.**

### 비용

폴드 하나가 늘면 학습이 50% 늘어납니다. 오늘 실험 기준 1시간이 1시간 30분이 됩니다.
**탐색은 2폴드로 하고, 통과한 것만 3폴드로 확인**하면 비용이 거의 안 늘어납니다.

## 7. 이번에 배운 것

**① 좋은 baseline 이 좋은 앵커가 아니다.**
`mix_yr` 은 소매가 배추에서 앵커 자체로는 현행보다 나은데(0.1193 vs 0.1377)
모델을 붙이면 집니다. **앵커가 정확할수록 모델이 배울 것이 줄어듭니다.**

**② 재현과 폴드는 다른 것을 막는다.**
새 시드 재현은 **우연**을 막고, 폴드 C 는 **한 시기에만 통하는 것**을 막습니다.
`mix_yr` 은 재현은 됐는데 폴드에서 떨어졌습니다. **둘 다 필요합니다.**

**③ 오늘 채택된 것은 하나뿐이다.**
feature 실험 넷 · 앵커 실험 하나 · 정의 실험 하나 = 여섯 중 **명절 feature 하나**.
**이 데이터에서 쉽게 얻을 것은 거의 남아 있지 않다는 뜻**으로 읽습니다
(CLAUDE.md 의 "우리 자료로는 큰 모델을 못 받친다" 와 같은 방향).
