## 2. 화면 문구 184개 전면 재작성

「내용을 이해할 수 없다」는 사용자 피드백에 따라 전면 재작성. 영어로 1차 이관 후 한국어로 재작성하는 방식을 채택함.

```
판정 불가  →  알 수 없음        «같다» 가 아니라 «모른다»
리드타임   →  며칠 뒤
앵커       →  출발점
현행       →  현재 모델
```

**단, 「경락가」·「중도매가」는 유지함.** 매입 담당자가 상시 사용하는 업계 용어로, 「경매 가격」으로 순화 시 오히려 재확인이 필요해짐. **난해한 용어와 익숙한 용어는 구분해야 함.**

### 2.1 백엔드 반환값은 원문 유지

`정상`·`후보가 낫다`·`배추` 등은 조회 조건이자 대조 기준이므로 변경 시 **에러 없이 0건**이 됨. 화면단에서 표시 문자열만 매핑(`labels.ts`).

**실제로 이 원칙을 위반하여 판정 배지 색상이 전부 회색으로 표시되는 결함 발생** — 색상 조회 키가 `정상` → `OK`로 함께 치환되어 어느 항목도 매칭되지 않음. 별도 커밋으로 복구.

## 4. 모델 재학습 자동화

기존에는 사용자가 「지금 판단하기」→「후보 모델 만들기」를 순차 클릭해야 비교표가 생성됨. **후보 생성은 운영 모델을 변경하지 않으므로 확인받을 이유가 없음.**

```
변경 후   배치가 전달표 송신 후 자동 수행
            판정 → (필요시) 후보 생성 → 성능 비교
          후보 우수 시   화면 탭에 적색 배지 · 비교표 · 「모델 업데이트」
          후보 열위 시   후보 삭제 후 미통보
```

**사용자 조작은 「모델 업데이트」 1회로 축소.**

### 4.1 후보 삭제 시 안전장치

이름이 `ops_{kind}_..._cand...` 인 항목만 삭제하며, 불일치 시 **아무것도 삭제하지 않고 사유를 기록.** 검증 완료:

```

ops_auc_교체전_20260909   미삭제 (백업)
```

현행 모델 성능이 양호하여 **「후보 우수 → 배지 표시」 경로가 미검증 상태**였음. 학습 기간만 2년으로 축소한 열위 모델(앵커 대비 열세)을 생성하여 운영 모델 자리에 임시 배치 후 전 구간 검증.

**적발 결함 3건 모두 에러를 발생시키지 않음.** 시뮬레이션 미실시 시 실제 재학습 필요 시점에 최초 인지했을 것임.

* **① 스레드 식별자 불일치** — 서버는 `retrain-auc`, 자동화 도구는 `auc` 조회. 동일 파일을 참조하나 다른 키를 조회하여, **배지는 표시되나 버튼이 동작하지 않음**
* **② 클릭 후에도 갱신 미반영** — 화면이 배치 저장 파일만 조회. 파일은 조식 시점 스냅샷이므로 클릭해도 불변. 창구가 그래프 상태를 재조회하도록 수정

시뮬레이션 도구는 `ops/retrain_sim.py`로 상시화(`start`·`restore`·`status`·`clean`).

## 8. 카드·차트 표시값 불일치 수정

동일 예측값이 카드 **422**, 차트 **423**으로 표시됨. 실제값은 **422.535**.

```
서버   int(422.535)        = 422    절사
화면   Math.round(422.535) = 423    반올림
```

서버를 반올림으로 통일. **절사는 방향성 오류를 수반함** — 매입가가 항상 소폭 저렴하게 표시되어 실제보다 저렴하다고 오인할 소지가 있음.
