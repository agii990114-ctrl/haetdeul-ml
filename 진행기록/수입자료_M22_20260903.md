# 수입 물량·가격 [M-22] — 구멍은 진짜였고, **그래서 못 씁니다**

작성 2026-09-03 17:00:07 · 햇들농산 ML 파트 (지환) · 백로그 [M-22]

---

## 한 줄로

**2019~2021 의 수입 자료 구멍은 수집 누락이 아니라 진짜입니다.
국산 양파가 그때 반값이라 수입할 이유가 없었습니다.
그런데 결측이 그 시기에 몰려 있어 feature 로 쓰면 시점 식별자가 됩니다.
안 씁니다.**

---

## 1. 먼저 — 수집 자체는 멀쩡합니다

구멍이 수입에만 있는지, 자료 전체에 있는지부터 봤습니다.

**우리 타겟 조건 (가락·특등급·규격 고정) 연도별 거래일**

```
2017  303일 · 2018 305 · 2019 305 · 2020 306 · 2021 302~304 · 2022 305 ...
```

**가락 전체 행수 · 규격 없는 행**

```
2019  19,234행 / 305거래일 / 규격 없는 행 0
2020  18,889행 / 306거래일 / 규격 없는 행 0
2021  17,724행 / 304거래일 / 규격 없는 행 0
```

**어디에도 구멍이 없습니다.** 수집 누락이라면 여기서 먼저 보여야 합니다.

---

## 2. ★ 수입 구멍은 진짜입니다 — 결정적 검사

**"수입이 잡힌 날" 만 골라 그날의 수입 물량을 봤습니다.**

```
수집이 빠진 것이면   있는 날의 물량은 평년과 같아야 한다
실제로 준 것이면     있는 날도 물량이 적다
```

| 연도 | 수입 있는 날 | **그날 평균 수입물량** | 그날 수입 비중 | 국산 양파 값 |
|---|---|---|---|---|
| 2017 | 277일 | **139.2톤** | 15.7% | 1,085원 |
| 2018 | 259일 | 59.4톤 | 6.3% | 710원 |
| **2019** | **97일** | **28.2톤** | **1.9%** | **534원** |
| **2020** | **99일** | **31.9톤** | **2.0%** | 880원 |
| **2021** | **92일** | **67.7톤** | **6.0%** | 900원 |
| 2022 | 149일 | 136.6톤 | 12.2% | 853원 |
| 2023 | 303일 | 148.9톤 | 12.5% | 1,204원 |
| 2025 | 305일 | 121.4톤 | 10.5% | 1,013원 |

**있는 날의 물량도 5배 줄었습니다** (139.2 → 28.2톤). 수집 누락이라면
이 칸은 안 움직여야 합니다.

### 이유가 분명합니다 — 국산이 반값이었습니다

**2019 국산 양파 534원은 시리즈 최저입니다** (2023 년의 절반 이하).
**국산이 반값이면 수입할 이유가 없습니다.**

> **백로그가 경고한 인과 역전이 자료로 확인됩니다.**
> *"국산 값이 비싸니까 수입을 들여오는 것"* — 2019 국산 534원에 수입
> 2,732톤, 2023 국산 1,204원에 수입 45,126톤입니다.

## 3. ★ 그런데 그게 곧 못 쓰는 이유입니다

**결측이 시기에 몰려 있습니다.**

```
수입이 없는 날의 비율
   2017~2018   10~16%
   2019~2021   68~70%     <- 학습 구간 한복판
   2023~2025    1~2%
```

**모델에게 "수입 단가 ÷ 국산 단가" 를 주면, 그 값이 비어 있는 것이
곧 "2019~2021년" 이 됩니다.**

이건 이미 두 번 겪은 함정입니다.

```
5.2절   경제 지표 — 월 단위라 같은 값이 한 달 반복 -> 시점 식별자
5.10절  학사일정 — 실측이 2020-09 부터라 결측이 시점 식별자
5.13절  뉴스심리지수 — 30일 평균이 "몇 년도인가" 를 알려줌
```

**세 번 다 같은 이유로 기각했습니다. 이것도 같습니다.**

### 결측을 메우는 것도 답이 아닙니다

`0` 으로 채우면 **"수입이 0" 과 "모름" 이 같아집니다** — 실제로는
2019~2021 에 수입이 아주 적었으니 0에 가깝긴 하지만, 그러면 **결측 패턴이
그대로 값에 실려** 여전히 시점 식별자가 됩니다.

프로파일(월×순 평균)로 메우면 시점 정보는 지워지지만, **그러면 "그해에
수입이 실제로 적었다" 는 신호도 같이 지워집니다.** 남는 게 없습니다.

```

배추   0.37% · 811일               신호 안 됨
무     0.04% · 60일                못 씀
```

**그리고 양파는 이미 우리가 제일 잘 맞히는 품목입니다** (경락가 오차 9.0% ·
배추 19.7%). **정작 나쁜 배추·무는 이 자료로 도울 방법이 없습니다.**
