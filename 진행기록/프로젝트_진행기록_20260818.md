## 3. 데이터 파이프라인 — 발견한 문제와 해결

실제 데이터를 검증하는 과정에서 정의서와 다른 사실이 여럿 확인됐다.
아래는 모두 **문서만 믿었다면 놓쳤을** 문제들이다.

### 3.1 단위 환산 규칙이 품목마다 다름

정의서에는 `exmn_dd_cnvs_prc` 가 kg환산가격으로 기재되어 있으나,
전체 377,230행 중 **32,325행(8.6%)만 실제로 환산**되어 있었다.

| 조합 | 건수 | 환산 여부 |
|---|---|---|
| 배추 중도매 kg(그물망 3포기) unit_sz=10 | 28,920 | ✗ |
| 양파 중도매 kg unit_sz=15 | 27,572 | ✓ |
| 양파 중도매 kg unit_sz=20 | 1,389 | ✓ |
| 배추 친환경 g unit_sz=100 | 3,366 | ✓ |

→ `exmn_dd_prc / unit_sz` 로 직접 계산. 환산 불가 단위(포기 등)는 NULL 로 제외해
**틀린 값이 조용히 섞이는 것을 차단**했다.

이를 놓쳤다면 배추 가격이 10배 틀린 채로 학습됐을 것이다.

### 3.2 주산지 매핑 4개월 오류

도메인 추정으로 만든 매핑을 `daily_volume` 의 실제 산지 물량과 대조한 결과
4개월이 실제와 달랐다.

| 월 | 기존 추정 | 실측 최다 산지 | 수정 |
|---|---|---|---|
| 5 | 해남 | 충남 예산군 53% | → 홍성 |
| 6 | 해남 | 강원 52% (횡성·평창) | → 대관령 |
| 9 | 대관령 | 강릉 23,755t > 평창 14,311t | → 강릉 |
| 10 | 해남 | 강원 평창군 88% | → 대관령 |

**10월 오류가 가장 중요**했다. 김장 직전 가격이 형성되는 구간을 남부(해남) 기상으로
보고 있었으나 실제 출하는 고랭지에서 이루어진다. 해당 구간의 기상 feature 전체가
엉뚱한 지역을 가리키던 상태였다.

부수적으로 관측소명 함정도 발견 — `고창`(172, 결측 42건)과 `고창군`(251, 결측 5건)이
별개 지점이며, 커버리지가 나은 고창군을 채택했다.

### 3.3 반입량 수집 지연 (누수 위험)

`daily_volume.req_date` 가 `base_date` 보다 0~3일 늦다.
기준일 당일에 어제 물량을 안다고 가정하면 백테스트가 낙관적으로 나온다.

```sql
WHERE v.req_date  <= t.base_dt      -- 기준일까지 수집 완료된 것만
  AND v.base_date <  t.base_dt      -- 당일 물량 제외
ORDER BY v.base_date DESC LIMIT 1
```

실측 지연: 평균 1.66일 · 최소 1일 · 최대 3일.

### 3.4 KREI 재배면적 3중 문제

| 문제 | 내용 | 해결 |
|---|---|---|
| 범위값 | VARCHAR 이며 `-8.1~-5.2` 형태 존재. 비숫자 제거 시 캐스팅 실패 | 숫자 토큰 추출 후 평균 |
| 작형 혼재 | 같은 달에 작형별 여러 행, **부호가 반대**<br>(2025-12: 가을배추 −4.1 / 겨울배추 8.5) | `krei_variety_pat` 정규식 선별 |
| 중복 | 493행 중 고유 조합 273개 | DISTINCT |

### 3.5 중기예보 확보 불가 → 평년기온 대체

과거 시점에 발표됐던 예보는 소급 확보가 원리적으로 불가능하다.
관측값을 대입하면 명백한 누수가 된다.

→ **평년 기온**으로 대체. 대상 구간의 과거 연도 같은 날짜대 평균을 쓰되,
기준일 이전 연도만 사용하고 참조 연도 3년 미만이면 NULL 처리했다.

검증: 참조 연도 수가 2015년 0개 → 2025년 10개로 매년 정확히 1씩 증가함을 확인(누수 0).

## 5. 모델 학습 결과

### 5.1 1차 시도 — 3년 데이터 (실패)

학습 2022~2024 (고유 기준일 735) / 검증 2025

| 구성 | WMAPE | baseline 대비 |
|---|---|---|
| baseline (어제 가격) | 0.1645 | — |
| LightGBM 절대가격 타겟 | 0.1699 | −3.3% |
| LightGBM 앵커 비율 타겟 | 0.1640 | +0.3% |

**baseline 을 유의미하게 넘지 못했다.** 개선율 +0.3% 는 시드 표준편차 0.0024(약 1.5%)
보다 작아 노이즈와 구분되지 않는다.

**진단 — 세 가지 독립 증거**

1. `best_iter` 가 1~12 (정상이면 수백~수천). 학습을 거의 못 한 상태
2. 유효 표본이 행수 13,230 이 아니라 **고유 기준일 735**
   (18행이 같은 기준일의 복제라 기준일 feature 는 18행 전부 동일)
3. 학습량 곡선이 단조가 아님 — 데이터를 더 주었는데 나빠짐

**추가 발견**: 연도별 가격 변동계수가 2022년 0.616, 2025년 0.270 으로 2배 이상 차이.
가장 요동친 해로 학습해 가장 잔잔한 해를 예측하는 구조였다.

### 5.2 앵커 타겟 변환 (구조 개선)

절대가격 대신 앵커 대비 로그 비율을 학습하도록 변경했다.

```
y = log(target_whsl_prc / whsl_prc_lag1)
예측 = whsl_prc_lag1 × exp(model_output)
```

**변경 전 문제**: `lead_biz_d` 중요도가 1.5% 에 그쳤고 WMAPE 가 리드타임 전체에서
0.156~0.188 로 평평했다. 모델이 리드타임을 무시하고 평균 가격 수준만 학습한 것이다.

| LT | 절대가격 타겟 | 앵커 비율 타겟 | baseline |
|---|---|---|---|
| 1 | 0.1563 (−95%) | **0.0820 (−2.4%)** | 0.0800 |
| 18 | 0.1875 (+11%) | 0.2064 (+1.7%) | 0.2100 |

모델이 0 을 출력하면 자동으로 baseline 과 같아지므로 크게 떨어질 위험이 사라진다.
덤으로 트리의 외삽 한계(학습 범위 밖 가격을 못 냄)도 완화된다.

### 5.3 2차 시도 — 11년 데이터 (성공)

학습 2015~2022 (고유 기준일 1,968) / 검증 2023~2025

| 항목 | 값 |
|---|---|
| baseline (어제 가격) | 0.2114 |
| **모델 (시드 앙상블)** | **0.1964** |
| **개선율** | **+7.1%** |
| 시드 표준편차 | 0.0031 (약 1.6%) |

**개선율이 표준편차의 4.5배** — 통계적으로 유의미하다.

### 리드타임별 — 설계 의도대로 작동

| 구간 | 개선율 | 해석 |
|---|---|---|
| LT 1~3 | −18.0% ~ −2.5% | 어제 가격이 이미 정답에 가까워 모델이 개입할 여지 없음 |
| **LT 4** | **+1.2%** | **역전 지점** |
| LT 7~18 | +7.6% ~ **+10.4%** | 관성이 약해지며 기상·수급 정보가 작동 |

LT12 에서 +10.4% 로 최고. **서비스 관점에서 가장 가치 있는 구간(2~3주 뒤 발주 판단)에서
가장 잘한다.**

### Feature Importance — 공들인 작업이 반영됨

```
whsl_prc_avg14         14.4%
prod_area_gdd_sum30    14.1%   ← 주산지 매핑 수정으로 만든 적산온도
whsl_prc_lag1           9.6%
holiday_remain_d        7.3%
whsl_prc_prev_yr        6.6%
ppi_idx                 6.3%
m2_growth_rt            5.8%
prod_area_temp_avg_lag1 5.4%   ← 산지 기온
crop_area_yoy_rt        3.9%   ← KREI 작형 선별로 바로잡은 재배면적
```

**주산지 기상 합계 21.9%** (GDD 14.1 + 기온 5.4 + 강수 2.4).
매핑 4개월을 실측으로 고친 작업이 결정적이었음이 수치로 확인됐다.

경제 변수(PPI 6.3 + M2 5.8)도 상위권이다. 선행연구(윤민정 외, 2024)에서 개선폭이
미미했던 변수들이 표본이 충분해지자 실제로 기여하고 있다.

### 구간별

| 구간 | 모델 | baseline | 개선 |
|---|---|---|---|
| 평상시 | 0.1943 | 0.2080 | +6.6% |
| 변동기 상위10% | 0.2144 | 0.2403 | +10.8% |

**가격이 요동칠 때 더 잘한다.** 평상시엔 예측이 필요 없고 급변할 때 필요하므로
실용적으로 더 가치 있는 구간이다.

### 5.4 두 번째 발견 — 무조건 오래된 데이터가 좋지는 않다

| 학습 시작 | 기준일 | 개선율 | 표준편차 |
|---|---|---|---|
| 2022 | 246 | +7.8% | 0.0011 |
| 2021 | 494 | +6.6% | 0.0006 |
| 2020 | 742 | +8.7% | 0.0012 |
| **2019** | **988** | **+11.2%** | 0.0026 |
| 2018 | 1,232 | +9.4% | 0.0013 |
| 2017 | 1,475 | +7.0% | 0.0001 |
| 2016 | 1,721 | +7.9% | 0.0022 |
| 2015 | 1,968 | +6.8% | 0.0031 |

**1,000개 근처에서 정점을 찍고 이후 하락**한다. 표준편차가 0.001~0.003 으로 작아
노이즈가 아니라 실제 경향이다.

2015~2018 의 시장 구조가 현재와 달라 오히려 방해가 되는 것으로 보인다.
유통 경로 변화, 재배 기술 변화, 기후 변화에 따른 주산지 이동 등이 원인일 수 있다.

## 8. 발표 시 서술 방향

### 데이터 품질 검증

> 정의서에 kg환산가격으로 기재된 컬럼이 실제로는 8.6%만 환산되어 있었고,
> 도메인 추정으로 만든 주산지 매핑은 실산지 데이터 대조에서 4개월이 틀렸다.
> 특히 김장 직전인 10월을 남부 기상으로 보고 있었으나 실제 출하는 고랭지였다.
> 스키마 문서와 실제 데이터는 반드시 대조해야 한다는 것을 확인했다.

### 모델 진단

> 3년 데이터(고유 기준일 735)로는 baseline 을 넘지 못했다. `best_iter` 한 자릿수,
> 개선율이 시드 표준편차보다 작음, 학습량 곡선 비단조 — 세 가지 독립 증거로
> 표본 부족을 진단했다. 유효 표본이 행수(13,230)가 아니라 고유 기준일(735)이라는
> 점도 함께 확인했다.
>
> 11년으로 확대하자 개선율이 +0.3% → +7.1% 로 상승했고 표준편차의 4.5배가 되어
> 통계적으로 유의미해졌다.

### 설계 검증

> 리드타임 4일에서 baseline 을 역전하고 7~18일 구간에서 +7.6~10.4% 개선을 보였다.
> 짧은 미래는 가격 관성이 지배하고 먼 미래는 수급·기상 정보가 작동한다는
> 설계 가설이 데이터로 확인됐다. feature importance 에서도 주산지 기상이 21.9%로
> 최상위권을 차지해, 매핑 수정 작업의 가치가 수치로 드러났다.

### 한계

> 중기예보는 과거 발표분 소급이 원리적으로 불가능해 평년기온으로 대체했다.
> 반입량은 원천 제약으로 2021-05 이후만 확보 가능하며, 산지폐기·수급조절 이력은
> 정형 데이터가 존재하지 않아 반영하지 못했다. 이들은 가격 급변의 주요 원인이므로
> 확보 시 추가 개선 여지가 있다.
