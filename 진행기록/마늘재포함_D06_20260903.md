## 한 줄로

**소분류가 저장되기 시작해 피마늘/깐마늘 구분 문제는 풀렸습니다.
그런데 마늘 경락 계열은 어떻게 걸어도 쓸 수 없습니다 —
규격을 고정할수록 나빠집니다. 배추와 정반대입니다.**

---

## 1. 막혀 있던 이유는 풀렸습니다

백로그에 이렇게 적혀 있었습니다.

> 피마늘/깐마늘 구분 미확정. 경락가 API 에 `gds_sclsf_cd`·`corp_gds_vrty_nm`
> 가 있으나 **수집기가 요청·저장하지 않는다**

**그 사이 저장되고 있습니다.** `subclass_name` 이 2017~2026 채워져 있습니다.

### 그리고 답이 나왔습니다 — 경락 시리즈는 사실상 피마늘입니다

```
가락 마늘 소분류 (2017~ · 물량 순)
   풋마늘         2,671톤     햇마늘 대서    1,976톤
   (빈값)        2,490톤     햇마늘 한지    1,262톤
   마늘쫑          795톤     마늘쫑(수입)     789톤
   저장형 한지      674톤     햇마늘 남도      491톤
   ...
   깐마늘 대서       18톤   <- 18행뿐. 사실상 없음
```

**깐마늘은 18행·18톤입니다.** CLAUDE.md 5.4절이 *"경락가·중도매가 모두
피마늘 계열"* 이라고 한 것이 맞습니다. **확인됐습니다.**

## 2. ★ 그런데 더 큰 이유가 나왔습니다

### 물량이 아주 적습니다

```
마늘 전체 (가락 · 2017~)   7,857톤
배추                     965,106톤     <- 마늘의 123배
양파                   1,726,499톤
```

### 규격이 흩어집니다

```
가락 마늘 특등급 안에서
   그물망 5kg   2,219톤   43%
   상자  15kg   1,328톤
   상자   8kg     670톤
   그물망 4kg     518톤
   그물망 3kg     423톤
```

**주력 규격이 43% 뿐입니다.** 배추는 그물망 10kg 가 **92%** 입니다.

### 소분류가 시기별로 갈립니다

```
햇마늘 대서   2021-06 부터만
홍산마늘      2026-06 부터만
쪽마늘        2025 년만
```

**2017~2026 을 관통하는 소분류를 고르기 어렵습니다.**

---

## 3. ★★ 결정적 — 규격을 고정할수록 나빠집니다

| 조건 | 거래일 | 빠진 날 | **ACF(1)** | 변동계수 | 물량 |
|---|---|---|---|---|---|
| ① 특등급만 (규격 무관) | 2,656일 | 10% | **0.574** | 0.407 | 7,857톤 |
| ② 특 + 그물망 5kg | 838일 | **71%** | **0.528** | 0.385 | 2,219톤 |
| ③ ② + 저장·햇마늘만 | 454일 | **85%** | **0.390** | 0.320 | 973톤 |

**견줄 값 — 배추: 2,929일 · ACF 0.928 · CV 0.500**

### 배추와 정반대입니다

```
배추   규격 고정 전 ACF 0.484  ->  고정 후 0.908     좋아짐
마늘   규격 고정 전 ACF 0.574  ->  고정 후 0.528     나빠짐
```

**왜 반대인가** — 배추는 주력 규격이 **92%** 라 규격을 걸면 **오염만
걷힙니다.** 마늘은 **43%** 라 걸면 **신호가 같이 날아갑니다.**
838일만 남고 71% 의 날이 비면, 날과 날 사이가 끊겨 어제-오늘 연결이
무너집니다.

**가장 느슨하게 걸어도 ACF 0.574 입니다.** 규격 사고 시절 배추(0.484)보다
조금 나은 수준입니다.

## 4. ★ 오늘 아침 발견과 이어집니다

오늘 **실험 도구가 마늘을 학습에 섞고 있었고, 그게 해로웠다**는 것을
찾았습니다.

```
배추 경락가   마늘 포함 0.2288 / 0.2611  ->  제외 0.2233 / 0.2505
```

**왜 해로웠는지 이제 설명됩니다.** 마늘 계열은 **ACF 0.574** 로 훨씬
어수선합니다. 그걸 같이 학습하면 **깨끗한 세 품목에 안 맞는 패턴을
배웁니다.**

**두 발견이 같은 이야기의 앞뒤입니다.**
