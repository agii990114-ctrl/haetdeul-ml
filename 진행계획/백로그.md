스프린트 백로그 항목의 ✅ 는 완료, ⬜ 는 미착수입니다.
제품 백로그가 v1 대비 바뀐 부분은 **굵게** 표시했습니다.

영어판은 `진행계획/backlog_EN.md` 에 있습니다. **원본은 이 파일입니다** — 둘이 다르면 이쪽이 맞습니다.

**갱신 2026-09-17 · 상태·수행 날짜 추가 · 근거는 git/PR/진행기록**

각 줄 끝에 **· 수행 …** 을 붙였습니다. 읽는 법 —

```
2026-09-03        그날 했다 (커밋·PR·문서로 확인)
~2026-08-25       그날까지 다 돼 있었다. 착수일은 모른다
날짜 미상          근거를 못 찾았다. 추측해서 채우지 않았다
미착수 · 수행 날짜 없음   아직 안 했다
```

날짜 근거는 셋뿐입니다 — root `git log` · `nobadai/mainproject` PR 병합 시각(KST 환산) ·
`진행기록/`·`실험결과/`·`연동/<날짜>/` 파일 이름과 CLAUDE.md 에 적힌 날짜.
**root git 이력은 2026-09-02 부터**라 그 이전 항목은 문서에 적힌 날짜가 유일한 근거이고,
문서에도 없으면 «날짜 미상» 입니다.

**기존 글자는 하나도 지우지 않았습니다.** 상태가 뒤에 바뀐 줄(TFT·GRU)은
원래 표시를 남기고 옆에 «★ 2026-09-10 완료 · 기각» 을 덧붙였습니다.
