> ## ⚠ 경락가 수치 전부 잠정 (2026-08-27)
>
> **경락가 타겟이 포장 규격 혼합이었습니다.** 배추 특등급 하루치에 15개 규격이
> 섞여 자기상관 ACF(1) 0.085 — 사실상 백색잡음을 예측하고 있었습니다.

> "앵커 대비" 값**입니다. 정정하면 경락가는 검증 2023 에서 14일평균에 집니다.

### [D-10] 경락가 규격 분리 ★★ 최우선 — 진행 중 (2026-08-27)

**타겟 자체가 잘못돼 있었습니다.** 오늘 잰 경락가 수치는 전부 무효입니다.

- **무엇이 문제인가**: 경락가 원천 API 는 거래 건별이고 **포장 규격별로 값이
  다릅니다.** 그런데 수집기가 (날짜·시장·품목·등급)으로 뭉쳐 저장하면서
  서로 다른 상품을 한 평균에 섞었습니다.

  가락 배추 특등급 2026-08-03 실측 — **15개 규격이 한 행에 있었습니다**

  | 규격 | 원/kg | 물량 |
  |---|---|---|
  | 그물망 10kg | **711** | 322,940kg (79%) |
  | 상자 4kg | 5,841 | 3,744kg |
  | 상자 1kg | **11,224** | 2,278kg |
  | **[가중평균 = 우리 타겟]** | **939** | |

  소분류도 섞였습니다 — 배추 안에 **쌈배추 156건 · 수입배추 · 생채용**.

- **피해 (실측)**

  | 지표 | 혼합(현행) | 규격 고정 |
  |---|---|---|
  | 배추 경락가 **자기상관 ACF(1)** | **0.085** | **0.795** |
  | 배추 변동계수 | 0.919 | 0.354 |
  | 일중 min/max 배수 | 132.7배 | 9.7배 |
  | 등급 역전(특<상) | 815일 중 **737일** | 해소 |

  **ACF 0.085 는 백색잡음입니다.** 예측할 수 없는 값을 타겟으로 삼고 있었고,
  어떤 feature 를 넣어도 나아질 수 없는 상태였습니다.
  무·양파는 규격이 균질해 피해가 작습니다 (무 0.788→0.822 · 양파 0.974→0.975).

- **확정한 규격** — 중량 기준. 포장 형태(그물망·파렛트·PE대)는 같은 중량이면
  물량가중으로 합칩니다. kg 단가가 서로 비슷해 같은 상품군입니다

  | 품목 | 규격 | 근거 |
  |---|---|---|
  | 배추 | **10kg** | 2015~2026 내내 물량 91~99% |
  | 무 | **18kg(~2018) → 20kg** | 2018년 포장 표준 전환. 전환기 단가차 3%로 계단 없음 |
  | 양파 | **15kg** | 그물망+파렛트 합산. 2015년부터 주력 |

- **등급은 특(11) 유지** — 매입 파트가 "상 등급"을 요청했으나 **가락 물량의
  98%가 특등급**이고, 양파 상 등급은 1년에 30~54일만 거래돼 시리즈를 만들 수
  없습니다. 배추 상 등급은 규격이 상자 8kg 로 달라 가격이 두 배입니다
  (1,411 vs 729원). 세 품목을 한 기준으로 묶으려면 특등급뿐입니다
