## 2. 3-타겟 구조

유통 3단계 가격을 각각 예측한다. 타겟마다 **짝이 되는 앵커**가 있다.

```
산지 → [경매] → 중도매인 → [판매] → 식당·소매상 → [소매] → 소비자
         ↑                    ↑                        ↑
  target_auc_prc      target_whsl_prc          target_rtl_prc
  (매입 판단)           (도매 매도)              (소매 매도)
```

| 타겟 | 앵커 | 상품·기준 | 사용자 |
|---|---|---|---|
| `target_auc_prc` | `auc_prc_lag1` | 서울가락 · 특등급(11) | 매입 |
| `target_whsl_prc` | `whsl_prc_lag1` | 가락도매 · 상품(04) | 도매 매도 |
| `target_rtl_prc` | `rtl_prc_lag1` | **서울(1101)** · 상품(04) | 소매 매도 |

앵커 변환 `y = log(target / anchor)` 을 쓰므로 **타겟과 앵커가 같은 계열**이어야
한다. 중도매가 타겟에 경락가 앵커를 쓰면 스케일이 어긋난다.

**학습 시 타겟 3종은 모두 입력에서 제외한다.** 서로의 정답이므로
하나라도 남으면 누수다.

## 4. 학습 시 설정

### 입력에서 제외 (11)

```
id · created_at · base_dt · target_dt
target_auc_prc · target_whsl_prc · target_rtl_prc   ← 서로의 정답
arr_qty_asof_date · arr_top1_region                 ← 진단용
prod_area_fcst_temp_avg10                           ← 전부 NULL
crop_area_yoy_rt                                    ← 결측 75%
school_open_ratio                                   ← ablation 기각 (5.10)
```

→ 나머지 **34개**가 실제 feature
(경제 3종을 더 빼면 31개. 소매가는 주산지 기상 7종까지 빼 24개)

### `crop_area_yoy_rt` 제외 사유

품목별 결측이 극단적이다.

```
배추 100%  ·  무 100%  ·  마늘 100%  ·  양파 1.4%
```

**사실상 "양파에만 있는 feature"** 가 되어 모델이 품목 식별자로 오용할 위험이
있다. KREI 작형 매칭이 3품목에서 실패한 결과다.

### categorical 지정 (3)

```
item_nm · target_dow · prod_area_stn_nm
```

### 기본 학습 품목

```
배추 · 양파 · 무
```

마늘은 제외한다. 피마늘/깐마늘 구분이 미확정이고, 중도매가가 94%의 날에
전일과 동일해 예측 문제로서 성격이 다르다. 테이블에는 남아 있으므로
`--items` 로 언제든 포함할 수 있다.

```
(달력 규칙) ──────────────────────────────────────────────→ target_dow · kimchi · holiday
```

### 소매가 집계 기준 변경 (2026-08-21)

전국 평균 → **서울(`sgg_cd='1101'`) 한정**으로 변경했다.

**이유**: 전국 기준일 때 2023년에 조사 점포가 44 → 59개로 늘어
학습 구간(2017~2022)과 검증 구간(2023~2025)의 집계 대상이 달라졌다.
중도매가는 가락도매 기준인데 소매만 전국이라 권역도 어긋났다.

**서울 소매 커버리지**: 배추 14,896건 / 양파 21,558건 / 무 16,411건,
각 2,699~2,701일, 점포 7~10개로 안정적.

> `rtl_prc_lag1`(앵커)과 `target_rtl_prc`(타겟)를 **반드시 함께** 갱신해야 한다.
> 한쪽만 고치면 "전국 평균으로 어제 가격을 주고 서울 가격을 맞추라"는
> 어긋난 문제가 된다.
