# 가격 예측 대시보드

`prediction_log` 를 읽어 예측 곡선·구간·정확도를 봅니다.
다른 파트가 소비할 값이 실제로 어떻게 생겼는지 확인하는 용도입니다.

---

## 실행

```bash
pip install streamlit psycopg[binary]
streamlit run 대시보드/streamlit_app.py
```

접속 정보는 **프로젝트 루트 `.env`** 의 `DATABASE_URL` 에서 읽습니다.
`st.secrets` 에 있으면 그쪽이 우선입니다.

```
DATABASE_URL=postgresql://사용자:비밀번호@호스트:5432/cost_catcher_raw
```

> `.env` 는 저장소 바깥으로 내보내지 마세요. 코드나 문서에 접속 정보를 쓰지 마세요.

### 선행 조건

`SQL/28_prediction_log.sql` 까지 실행돼 있어야 합니다.
비어 있으면 대시보드가 무엇을 실행해야 하는지 알려주고 멈춥니다.

## 화면

| 영역 | 내용 |
|---|---|
| KPI | 기준일 · 예측 행 수 · 채점된 평균 오차율 · 권장 품목 수 |
| **예측 곡선** | 대상일별 예측선 + 구간 음영 + 앵커 기준선 + 실제값(있으면) |
| 리드타임별 오차 | 채점된 예측의 평균 절대오차율. 멀리 볼수록 커지는 것이 정상 |
| 품목별 신뢰도 | 검증·테스트 개선율. 0 미만이면 모델을 쓰면 안 됨 |
| 예측 원본 | 표 |
| 예측 구간의 근거 | 리드타임별 구간 폭 |

사이드바에서 **예측 단계**(경락/중도매/소매) · **품목** · **기준일**을 고릅니다.

---

## 읽는 법

**단위가 타겟마다 다릅니다.** 그래서 화면에서 한 번에 한 단계만 봅니다.
소매가의 배추는 kg 이 아니라 **포기** 단위라 다른 품목과 자릿수가 다릅니다.

**음영은 예측 구간(q10~q90)** 입니다. 검증 구간 실적상 10건 중 8건이 이 안에
들어왔다는 뜻입니다. 시드 편차가 아닙니다 — 시드 편차는 1.6~1.8% 인데 실제
오차는 10~17% 로 자릿수가 달라, 그걸 구간으로 쓰면 불확실성을 크게
과소평가합니다.

**점선은 앵커**(기준일 시점 최신 실제가)입니다. 모델이 앵커를 이기지 못하는
조합에서는 그 선이 답입니다. 어느 조합이 그런지는 "품목별 신뢰도" 가 알려줍니다.

**리드타임 1~2 는 게이트**라 예측선이 앵커와 겹칩니다. 버그가 아닙니다.

## 현재 데이터

`model_ver = 'dummy-v0'` 인 더미가 들어 있으면 화면 상단에 경고가 뜹니다.
앵커·대상일·정답은 실제 값이고 **예측가만 만들어낸 값**입니다.
연동 확인용이며 사업 판단에 쓰면 안 됩니다.

실제 예측이 들어오면 `model_ver` 가 `whsl-20260824` 같은 값이 되고 경고가 사라집니다.

## 구조

```
대시보드/
  streamlit_app.py   화면
  db.py              조회 (캐시 TTL 10분)
```

`db.py` 는 연결을 캐시하지 않고 조회할 때마다 짧게 열고 닫습니다.
조회 빈도가 낮은데 캐시된 연결은 방치되면 서버가 끊어 다음 조회에서
알 수 없는 오류가 나기 때문입니다.
