## 1. 강수량 결측 오탐 대응 및 수동 재실행(Rerun) 버튼 신설
기상청 비 미관측일(0mm)을 결측으로 오판한 수집 검사 때문에 09:00 배치가 중단되는 사고가 발생했다.
- **조치**: 강수량 검사를 판정에서 제외(수치는 유지)하고, 콘솔 화면에 **"배치 즉시 재실행"** 및 **"AI 리포트 즉시 생성"** 버튼을 신설했다. 중복 실행으로 인한 테이블 비움 사고를 방지하기 위해 단일 작업 락(Lock)과 3초 폴링 비동기 아키텍처를 적용했다.

## 2. 재학습 알림 문턱: 3주 → 1주로 단축
2026년 32주간의 이력을 되감기(Replay) 시뮬레이션한 결과, 배추 경락가와 양파 소매가 등 주요 품목의 최장 연속 악화 주수가 2주에 불과했다. 즉 '3주 연속 악화 시 재학습'이라는 기존 기준은 사실상 감지 기능이 꺼져 있는 상태였다.
- 문턱을 **1주**로 단축했다. 헛울림이 발생하더라도 후보 모델을 만들어 비교한 뒤 패배하면 조용히 폐기되므로 운영 비용은 2.5분에 불과하다.

## 3. ★ 시퀀스 딥러닝 모델(TFT, LSTM, GRU) 전원 기각
시계열 전용 딥러닝 모델이 LightGBM을 이길 수 있는지 확인하기 위해 동일 조건(56일 과거 윈도우, 미래 확정 변수 7종, 앵커 포함)으로 엄정하게 평가했다.
- **결과 (Lead ≥ 3 WMAPE)**:
  - 폴드 A: 앵커 0.1730 / LightGBM **0.1667** / TFT 0.2341 / LSTM 0.2308 / GRU 0.2689
  - 폴드 B: 앵커 0.2096 / LightGBM **0.1956** / TFT 0.2873 / LSTM 0.3477 / GRU 0.4001
- **원인 분석**: 24개 평가 셀 중 23개에서 LightGBM에 완패했다. 약 1,475개에 불과한 기준일 데이터 환경에서는 복잡한 딥러닝 모델이 50스텝 만에 심각한 과적합에 빠지기 때문이었다. 반면 트리 기반 LightGBM은 50~76그루만으로도 최적의 일반화 성능을 냈다. 딥러닝 모델 도입을 최종 기각했다.
