````markdown
## 1. 리드 0일차(Lead 0) 도입: 오늘 밤 경매가 예측
가락시장 경매는 야간에 열리고 배치는 아침 09:00에 실행되므로, 기준일 당일 밤에 열릴 경매는 아직 발생하지 않은 미래다.
- 기존에 1영업일(Lead 1)부터 시작하던 테이블을 리드 0일차까지 확장하여 오늘 밤 경락가 예측을 제공했다.
- 리드타임 게이트를 `{경락가: 0, 중도매가: 3, 소매가: 0}`으로 조정하여 당일 경락가 모델 출력을 활성화했다.

## 2. 4대 콘솔 탭 구축 및 Pure SVG 차트
`가격 예측 · 배치 상태 · AI 리포트 · 모델 재학습`의 4대 탭으로 구성된 사내 콘솔을 구축했다.
- 일반 차트 라이브러리가 채점 전 미래 날짜의 결측값을 0원으로 이어 붙여 가격 폭락처럼 보이는 치명적 착시를 유발함을 발견하고, 외부 라이브러리 없이 **순수 SVG 렌더링**으로 차트를 구현하여 미도래 구간을 깔끔하게 절단 표현했다.

## 3. 고의 열위 모델을 통한 재학습 승인 경로 스트레스 검증
재학습 승인 경로가 실제로 잘 작동하는지 검증하기 위해 2년치 데이터로 학습된 고의 열위 모델을 운영 슬롯에 임의 배치하고 배치를 돌렸다.
- 이 과정에서 에러 없이 묻힐 뻔한 3가지 결함을 발견하고 완벽히 수정했다:
  1. 스레드 ID 불일치로 버튼 클릭이 무반응하던 문제
  2. 이미 처리된 결정이 화면에 잔존하던 오래된 스냅샷 캐시 문제
  3. LangGraph 상태 필드 누락으로 'discarded'가 'stopped'로 오인되던 문제
````
