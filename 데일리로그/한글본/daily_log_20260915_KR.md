**content** `(1,987 / 6,000자)`

오늘 가격 전망 Q&amp;A 에이전트를 단순 테스트 엔드포인트에서 마스터 에이전트가 직접 호출할 수 있는 구조로 전환했습니다. 이후 실제 콘솔 환경에서 테스트를 진행하며 5가지 해석 결함을 발견하여, 리뷰 진행 중인 1건을 제외한 모든 문제를 수정했습니다.

**1. API 없는 마스터 연동**

다른 모듈과 마찬가지로 HTTP 호출 대신 마스터의 요청을 받아 응답과 실행 메타데이터를 반환하는 프로세스 내 함수 형태로 연동했습니다. 기존 테스트 API는 계속 활용하기 위해 유지했습니다.
마스터 측 검증 과정에서 첫 버전이 거절되었습니다. 모든 주장 수치가 예측값 행 등 데이터 주소를 명시해야 한다는 요구에 따라 응답 구조를 재설계했습니다. 또한 질문을 단일 키로만 읽고, 시리즈 식별자 등 코드용 용어를 응답 텍스트에서 제외하도록 수정했습니다. 해당 포트는 PR #687로 머지되었으며 마스터 측에도 등록되었습니다.

**2. 영어 프롬프트 비교 검증**

영어 지시문이 더 좋은 결과를 낸다는 주장을 검증하고자 동일 모델·온도·스키마 환경에서 프롬프트 언어만 달리하여 12개 질문을 테스트했습니다.

```text
1-2회차 (96개 항목)   한국어 100.0%   영어 93.8%
3회차   (48개 항목)   한국어  97.9%   영어 95.8%

```

영어 프롬프트는 "오늘 양파 도매가"를 매번 "경매가"로 오해했습니다. 작물과 가격 명칭이 한국어이므로 영어 프롬프트 적용 시 불필요한 번역 단계가 추가되어 오작동을 유발했습니다. 이에 따라 한국어 프롬프트를 기본값으로 유지합니다.
*(첫 테스트 시 한국어 요청이 연속 실행되어 무료 API 제한(분당 15회)을 초과, 영어 요청 24건이 모두 거절되는 문제가 발생했습니다. 이후 벤치마크 로직을 개선하여 호출 간격을 조절하고 실패 건수를 별도 집계하도록 수정했습니다.)*

**3. 날짜 선택 방식 개선 (목록 기반 선택)**

"매일" 조회 요청 시 1일 치만 반환하던 문제를 해결하기 위해, 오늘부터 18일 뒤까지의 19개 날짜 목록을 코드로 생성하여 LLM이 이 목록 내에서만 선택하도록 제한했습니다.
또한 스키마에서 날짜가 옵션으로 설정되어 있어 모델이 날짜를 생략하던 현상을 막기 위해 모든 필드를 필수(required)로 변경했습니다. 날짜 지정이 없으면 오늘 날짜를 기준으로 안내하며, 정보가 부족할 경우 미흡한 부분만 추가 요청하도록 개선했습니다.

**4. 다중 작물 및 다중 시리즈 처리**

"배추 경매가 및 도매가"처럼 복수 조회가 필요한 경우 작물과 시리즈를 명시적 쌍(pair)으로 반환하도록 구조화했습니다. 질문에 없는 가격 유형까지 임의로 추가하는 현상을 막기 위해, 질문에 명시되지 않은 시리즈는 코드 규칙으로 자동 제거하도록 처리했습니다.

**5. "오늘" 날짜의 미래 조회 오류 수정**

오늘 가격 조회 시 콘솔 설정 날짜가 아닌 예측 로그의 최신 기준일을 참조하여, 2월 콘솔 환경에서 9월 15일 데이터가 조회되던 오류를 수정했습니다. 조회가 콘솔 기준일에 정확히 귀속되도록 로직을 고쳤습니다.

**6. 범위 벗어난 날짜 요청 처리**

"30일 뒤 무 가격" 요청 시 목록에 없는 날짜를 떨어뜨리고 기본값(오늘)을 반환하던 문제를 수정했습니다. 범위를 벗어난 오프셋을 별도 리포팅하도록 변경했으며, 응답 가능한 날짜 범위를 안내하도록 개선했습니다 (PR #707 리뷰 진행 중).

**7. 기타 소형 결함 수정**

* DB의 소수점 현재가가 스키마 정수형과 충돌하여 500 에러가 발생하던 현상을 반올림 처리로 해결.
* 테스트 파일명 중복으로 인한 pytest 수집 오류를 해결하기 위해 어댑터 테스트 파일명 변경.
* 벤치마크 스크립트 위치를 모듈 내부 폴더로 이동.
* 응답 텍스트를 간결화하고, 휴일 복사값 안내 문구를 "휴일의 경우 직전 예측값을 사용합니다."로 정돈.

**8. 구매(Purchase)팀 전달 사항**

19개 예측값 전체 전달을 제안했으나, 구매팀은 14일 차 의사결정 행에 이미 리드타임이 포함되어 있어 수신기 로직을 변경하지 않겠다는 의사를 전달받았습니다. 또한 구매팀 계약상 첫 행이 내일이어야 하므로 배열에 '오늘'을 포함할 수 없음을 안내했습니다.

**9. 도메인 환경 테스트 제약**

팀 도메인은 배포된 main 이미지를 바라보고 있어 오늘 작업분이 반영되지 않았습니다. 해당 환경 테스트를 위해서는 dev-to-main 머지 및 컨테이너로의 ML 콘솔 주소 전달이 선행되어야 합니다.
